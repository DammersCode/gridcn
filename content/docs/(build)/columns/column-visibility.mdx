Users hide the columns they do not need. `hidden: true` starts a column hidden. `setColumnHidden` toggles a column from code. `DataGridColumnsMenu` gives users a checkbox for each column.

## Hide and show columns [#visibility]

`hidden: true` in a `ColumnDef` sets the first state. `setColumnHidden(id, hidden)` and the columns menu override it. The flag applies once for each column id, when the id first appears. A new `columns` array keeps the visibility of the columns it already has and seeds only new ids.

`DataGridColumnsMenu` ships with the [toolbar add-on](/docs/sort-filter-search/toolbar). It is a dropdown with a checked row for each column. The header menu of the [context menu add-on](/docs/rows-pages-menus/context-menu#header-surface) has a "Hide column" item.

`hideable: false` protects a key column. The columns menu shows its row checked and turned off while the column is visible. If code hid the column, the row is unchecked and a click shows the column again. The header menu has no "Hide column" item. `setColumnHidden`, URL state, saved views, and `hidden` still apply to the column. This sample sets `hideable: false` on the name column:

```tsx
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  defineColumns,
} from "@/components/data-grid/data-grid";
import {
  DataGridColumnsMenu,
  DataGridToolbar,
} from "@/components/data-grid-toolbar/data-grid-toolbar";

type Row = { id: string; name: string; email: string };

const rows: Row[] = [{ id: "1", name: "Ada", email: "ada@example.com" }];
const columns = defineColumns<Row>()([
  { id: "name", header: "Name", accessorKey: "name", hideable: false },
  { id: "email", header: "Email", accessorKey: "email", hidden: true },
]);

export function ColumnsGrid() {
  return (
    <DataGridProvider defaultData={rows} columns={columns}>
      <DataGridToolbar>
        <DataGridColumnsMenu />
      </DataGridToolbar>
      <DataGridRoot className="h-80">
        <DataGridHeader />
        <DataGridBody />
      </DataGridRoot>
    </DataGridProvider>
  );
}
```

Result: the grid starts with the Name column. The menu shows Name checked and turned off, and Email unchecked.

## Read column state [#reading-column-state]

These hooks read column state for your own UI. Call them under `DataGridProvider`.

| Hook | Returns |
| --- | --- |
| `useDataGridVisibleColumns()` | the columns that are not hidden, in display order |
| `useDataGridAllColumns()` | every column, hidden ones included, in column order |
| `useDataGridIsColumnHidden(id)` | `true` while the column is hidden |
| `useDataGridColumnWidth(id)` | the stored width in px, or `undefined` while the column has none |
| `useDataGridColumnWidths(ids)` | the stored widths of a list of columns |

The visible and all-columns hooks return the full `ColumnDef` of each column. Pass your row type, for example `useDataGridVisibleColumns<Row>()`, to type `accessorFn` and `setValue`. The actions of `useDataGridActions()` write the state: `setColumnWidth`, `previewColumnWidth`, `resetColumnWidth`, `setColumnOrder`, `setColumnPin`, `setColumnHidden`, `setColumnLayout`, and `autosizeColumns`. This sample shows a button for each hidden column:

```tsx
import {
  useDataGridActions,
  useDataGridAllColumns,
  useDataGridIsColumnHidden,
} from "@/components/data-grid/data-grid";

function ShowButton({ id, label }: { id: string; label: string }) {
  const actions = useDataGridActions();
  const hidden = useDataGridIsColumnHidden(id);
  if (!hidden) return null;
  return (
    <button onClick={() => actions.setColumnHidden(id, false)}>
      Show {label}
    </button>
  );
}

function RestoreBar() {
  return useDataGridAllColumns().map((column) => (
    <ShowButton
      key={column.id}
      id={column.id}
      label={
        column.headerText ??
        (typeof column.header === "string" ? column.header : column.id)
      }
    />
  ));
}
```

## Save the layout [#persisting-a-users-layout]

[Save a column layout](/docs/columns/column-layout) stores hidden columns with widths, order, and pins.

## Server mode

The layout is browser state in every data mode. `fetchRows` gets no list of hidden columns. A hidden column still loads its data. To keep a field from the browser, leave it out of the server response: see [Lock cells by role](/docs/editing-cells/lock-cells-role).
