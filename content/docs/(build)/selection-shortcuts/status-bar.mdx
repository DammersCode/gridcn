Users read totals of a selection without exporting it. `data-grid-status-bar` computes them from the grid's own data. `<DataGridStatusBar />` renders the bar, and `useDataGridSelectionStats` is the headless hook. Both read committed values only, never the draft of an open editor, and write nothing, so `readOnly` grids work unchanged. For a total of a whole column that stays in sight, use a [pinned totals row](/docs/rows-pages-menus/pinned-rows).

The `data-grid-status-bar` item depends on the shadcn `button` component. Place the bar inside `DataGridProvider`, next to `DataGridRoot`:

```tsx
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  defineColumns,
} from "@/components/data-grid/data-grid";
import { DataGridStatusBar } from "@/components/data-grid-status-bar/data-grid-status-bar";

type Sale = { id: string; region: string; amount: number };

const columns = defineColumns<Sale>()([
  { id: "region", header: "Region", accessorKey: "region", type: "text" },
  { id: "amount", header: "Amount", accessorKey: "amount", type: "number" },
] as const);

export function SalesGrid({ sales }: { sales: Sale[] }) {
  return (
    <DataGridProvider
      data={sales}
      columns={columns}
      getRowId={(sale) => sale.id}
    >
      <DataGridRoot className="h-80">
        <DataGridHeader />
        <DataGridBody />
      </DataGridRoot>
      <DataGridStatusBar />
    </DataGridProvider>
  );
}
```

## Which cells count [#which-cells-count]

The bar aggregates the union of every selection channel: the primary range, the stacked <kbd>Ctrl</kbd>/<kbd>Cmd</kbd>+click ranges, whole-row selections, and whole-column selections. A cell that sits in two channels counts once. Hidden columns and filtered-out rows are outside the view, so they never count. The unloaded rows of a source in scroll mode have no value and count as nothing. With client pagination, the grid keeps every row, but a selection covers the shown page only. So the bar aggregates the cells of that page.

## Which values count [#which-values-count]

A cell counts as numeric if its raw value is a finite `number`. Detection reads the value, so a custom numeric cell type aggregates without configuration. `count` counts the non-empty cells, where empty means that the `isEmpty` of the column's cell type returns `true`. `sum`, `avg`, `min`, and `max` run over the numeric cells. The sum uses Neumaier compensated summation to limit floating-point error.

## Display and formatting [#display-and-formatting]

The aggregates show once the selection covers two loaded cells. `count` always shows. `sum`, `avg`, `min`, and `max` show only with a numeric cell in the selection.

When every numeric cell comes from one column, the `toDisplayText` of that column formats `sum`, `avg`, `min`, and `max`. A `number` column with a `format` option shows currency. Otherwise the bar uses `Intl.NumberFormat(locale, { maximumFractionDigits: 4 })`. `formatValue` overrides both.

The bar also shows the count of [hidden checked rows](/docs/selection-shortcuts/checked-rows#hidden-checked-rows) as `(+3 hidden)`, and the select-all banner of a [server grid](/docs/rows-live-data/select-server-rows). With nothing to show, it renders nothing.

## Select-all banner [#select-all-banner]

<NewBadge />

A grid with `totalRowCount` shows a banner when every row of the page is checked and the result is larger. The banner needs `checkedRowsLifetime="across-filters"`, which is the default with `totalRowCount`. The banner offers "Select all 237 matching", or "Select all matching" when the size is `null`. After the click, it reads "All 237 selected." with a "Clear selection" button. `selectAllMatching()` announces the real count in the live region, or "All matching rows checked" when the size is `null`.

Set the banner text with `labels.statusBar.pageSelected`, `selectAllMatching`, `allSelected`, and `clearSelection`. `selectAllMatching` and `allSelected` take `null` for an unknown size. The bar aggregates the selected cells, which sit on the current page.

## When it computes [#when-it-computes]

The hook recomputes after the selection settles. A selection whose ranges cover up to 5,000 cells computes at once. A larger selection computes on a 150 ms trailing timer, so dragging a large range does not walk the whole selection on every frame.

A walk stops at 200,000 cells (`MAX_STATUS_CELLS`). Above the cap, every value gets a `≈` prefix, and the `title` of the bar says how many cells the values cover.

## Headless hook

`useDataGridSelectionStats()` returns the numbers for your own UI. Call it inside `DataGridProvider`:

```tsx
import { useDataGridSelectionStats } from "@/components/data-grid-status-bar/data-grid-status-bar";

export function SelectionSum() {
  const { sum, approximate } = useDataGridSelectionStats();

  const prefix = approximate ? "≈" : "";

  return <span>{sum === null ? "No numbers" : `${prefix}${sum}`}</span>;
}
```

The result holds `cells`, `count`, `numeric`, `sum`, `avg`, `min`, `max`, `numericColumnId`, and `approximate`. The aggregates are `null` without numeric cells. `numericColumnId` is `null` if the numeric cells span several columns.

## Props [#props]

{/* props: DataGridStatusBarProps */}

| Prop | Type | Default | Description |
|---|---|---|---|
| `aggregates` | `readonly ("count" \| "sum" \| "avg" \| "min" \| "max")[]` | all five, in this order | Which aggregates to show, and in which order. |
| `formatValue` | `(value: number, aggregate: StatusBarAggregate) => string` | the single-column rule, else the `Intl` default | Formats the shown aggregate values. |
| `locale` | `string` | `"en-US"` | Locale for the default number format. |
| `labels` | `Partial<DataGridStatusBarLabels>` | merged over `labels.statusBar` | Overrides the strings of this bar. |
| `className` | `string` | none | Extra classes on the bar element. |
| `children` | `ReactNode` | none | Extra items, rendered after the aggregates. |

<Callout type="idea" title="The bar is a polite live region">
  The bar is `role="status"` with `aria-live="polite"` and `aria-atomic="true"`. Each value sits next to its label, for example "Sum 1,234".
</Callout>
