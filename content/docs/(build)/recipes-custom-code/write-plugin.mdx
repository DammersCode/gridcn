Write a plugin to paint on the grid, observe data changes, or add a command. This task builds a plugin that tints one column. A plugin object holds the parts it needs, and `name` is the only required part.

## Before you start

- Mount a grid with `columns` and `data`.
- Know that a plugin object attaches to one grid. Create one object per grid.
- Know the coordinates. A view index is a row position in the sorted and filtered order. A rect is `{ x, y, width, height }`: `x` is a visible column index and `y` is a view index. A pin zone is the pinned-left, unpinned, or pinned-right part of the grid.
- Pick the part. `Overlay` paints, `rowBands` adds rows, and `onDataChange` observes writes. `commands` adds commands. `keymap` binds keys to the commands of the plugin. A key that another action holds stays with that action. The grid renders `Mount` inside the grid root.

## Steps

1. Write a component that takes the overlay `ctx` and returns the band. The grid renders it after the selection fills and before the active-cell ring.
2. Build a rect. Use `ctx.clampRowStart` and `ctx.clampRowEnd` for the rows.
3. Call `ctx.clampRectToWindow(rect, clampRowStart, clampRowEnd, colCount)`. If the rect lies outside the rendered rows, it returns `null`.
4. Check `hasAnyPin(ctx.pinTrack)`. If it is true, call `ctx.splitRectByPinZones(clamped, ctx.pinTrack)`. It returns one segment for each pin zone that the rect crosses, up to three.
5. Spread the `pinStyle` of a pinned segment into its style. Set `zIndex: GRID_LAYER.pinnedOverlaySegment`, so the band paints above the pinned cells.
6. Place every segment on the grid lines. Add `ctx.colOffset` to `rect.x` for columns, and use `rect.y - ctx.windowStart + 1` for rows. `windowStart` is the grid line origin of the rows canvas. Set `position: "relative"`. Cells have a position, so a static band paints below them.
7. Read the column from React context and not from a closure. A new `Overlay` function remounts the overlay and logs a warning in development.
8. Return `{ name, Overlay }` from a factory and pass the result in `plugins`.

## Paint a column

The sample below does all eight steps. `./orders` stands for your own module of `columns` and `orders` rows. Create the plugin once per grid with `useState`:

```tsx
"use client";

import { createContext, useContext, useState } from "react";
import {
  DataGrid,
  type DataGridPlugin,
  type GridRect,
  type OverlayPluginCtx,
} from "@/components/data-grid/data-grid";
import { GRID_LAYER, hasAnyPin } from "@/components/data-grid/data-grid-sdk";
import { columns, orders } from "./orders";

const HighlightedColumn = createContext<number | null>(null);

type BandProps = { column: number; ctx: OverlayPluginCtx };

function ColumnBand({ column, ctx }: BandProps) {
  const { clampRowStart, clampRowEnd, colCount } = ctx;
  const { colOffset, windowStart } = ctx;
  const rect: GridRect = {
    x: column,
    y: clampRowStart,
    width: 1,
    height: clampRowEnd - clampRowStart,
  };
  const clamped = ctx.clampRectToWindow(
    rect,
    clampRowStart,
    clampRowEnd,
    colCount,
  );
  if (!clamped) return null;
  const segments = hasAnyPin(ctx.pinTrack)
    ? ctx.splitRectByPinZones(clamped, ctx.pinTrack)
    : [{ rect: clamped, pinStyle: undefined }];
  return segments.map(({ rect: part, pinStyle }, index) => (
    <div
      key={index}
      aria-hidden="true"
      className="pointer-events-none bg-primary/10"
      style={{
        position: "relative",
        gridColumnStart: part.x + colOffset,
        gridColumnEnd: part.x + part.width + colOffset,
        gridRowStart: part.y - windowStart + 1,
        gridRowEnd: part.y + part.height - windowStart + 1,
        ...pinStyle,
        ...(pinStyle ? { zIndex: GRID_LAYER.pinnedOverlaySegment } : {}),
      }}
    />
  ));
}

function ColumnOverlay(ctx: OverlayPluginCtx) {
  const column = useContext(HighlightedColumn);
  return column === null ? null : <ColumnBand column={column} ctx={ctx} />;
}

function createColumnHighlight(): DataGridPlugin {
  return { name: "column-highlight", Overlay: ColumnOverlay };
}

export function OrdersGrid() {
  const [column, setColumn] = useState<number | null>(null);
  const [plugin] = useState(createColumnHighlight);
  return (
    <HighlightedColumn.Provider value={column}>
      <button onClick={() => setColumn(1)}>Highlight the second column</button>
      <DataGrid
        className="h-96"
        defaultData={orders}
        columns={columns}
        plugins={[plugin]}
      />
    </HighlightedColumn.Provider>
  );
}
```

## Result

A click on the button tints the second column across the rendered rows. The band lives in the scrolling canvas, so it moves with the cells. It splits at pinned columns. The active-cell ring stays above it.

An inline `plugins={[plugin]}` array is safe while the plugin object keeps its identity. A new object with the same `name` and a changed member makes the grid resolve the plugins again.
