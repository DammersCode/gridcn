Write a plugin to paint on the grid, observe data changes, or add a command. This task builds a plugin that tints one column. A plugin object holds the parts it needs, and `name` is the only required part.

## Before you start

Mount a grid with `columns` and `data`.

## Coordinates

A view index is a row position in the sorted and filtered order. A rect is `{ x, y, width, height }`: `x` is a visible column index and `y` is a view index. A pin zone is the start side, the unpinned middle, or the end side of the grid.

A plugin object attaches to one grid, so create one object per grid. Pick the part you need:

- `Overlay` paints.
- `rowBands` adds rows.
- `onDataChange` observes writes.
- `commands` adds commands, and `keymap` binds keys to them. A key that another action holds stays with that action.

The grid renders `Mount` inside the grid root.

## Steps

1. Write a component that takes the overlay `ctx` and returns the band. The grid renders it after the selection fills and before the active-cell ring.
2. Return `OverlayRect` with the `ctx` and a rect. It clamps the rect to the rendered rows, splits it at pinned columns, and places each part on the grid lines. Style it with `className`.
3. Read the column from React context and not from a closure. A new `Overlay` function remounts the overlay and logs a warning in development.
4. Return `{ name, Overlay }` from a factory and pass the result in `plugins`.

## Paint a column

The sample below does all four steps. `./orders` stands for your own module of `columns` and `orders` rows. Create the plugin once per grid with `useState`:

```tsx
"use client";

import { createContext, useContext, useState } from "react";
import {
  DataGrid,
  type DataGridPlugin,
  type OverlayPluginCtx,
} from "@/components/data-grid/data-grid";
import { OverlayRect } from "@/components/data-grid/data-grid-sdk";
import { columns, orders } from "./orders";

const HighlightedColumn = createContext<number | null>(null);

function ColumnOverlay(ctx: OverlayPluginCtx) {
  const column = useContext(HighlightedColumn);
  if (column === null) return null;
  const rect = {
    x: column,
    y: ctx.clampRowStart,
    width: 1,
    height: ctx.clampRowEnd - ctx.clampRowStart,
  };
  return <OverlayRect ctx={ctx} rect={rect} className="bg-primary/10" />;
}

function createColumnHighlight(): DataGridPlugin {
  return { name: "column-highlight", Overlay: ColumnOverlay };
}

export function OrdersGrid() {
  const [column, setColumn] = useState<number | null>(null);
  const [plugin] = useState(createColumnHighlight);
  return (
    <HighlightedColumn.Provider value={column}>
      <button onClick={() => setColumn(1)}>Highlight the second column</button>
      <DataGrid
        className="h-96"
        defaultData={orders}
        columns={columns}
        plugins={[plugin]}
      />
    </HighlightedColumn.Provider>
  );
}
```

## Result

A click on the button tints the second column across the rendered rows. The band lives in the scrolling canvas, so it moves with the cells. It splits at pinned columns. The active-cell ring stays above it.

An inline `plugins={[plugin]}` array is safe while the plugin object keeps its identity. A new object with the same `name` and a changed member makes the grid resolve the plugins again.
