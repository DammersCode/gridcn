Four default props seed the view once: `defaultSortState`, `defaultFilterState`, `defaultSearchText`, and `defaultColumnLayout`. Each one has a change callback. Save from the callbacks and seed from the saved value.

## Before you start

- Pick a place to store the view. The sample uses `localStorage`.
- Give every column a stable `id`. A saved sort, filter, or layout names columns by id.

## Steps

1. Read the saved view after the first render. Reading `localStorage` earlier makes the server and the first client render differ.
2. Render the grid after the saved view loads.
3. Pass the saved parts as the four default props.
4. Save the new value in each of the four callbacks.

## Save and restore the view

The sample merges every callback into one stored object. `./orders` stands for your own module of `columns` and `orders` rows:

```tsx
"use client";

import { useEffect, useState } from "react";
import {
  DataGrid,
  type ColumnLayout,
  type FilterNode,
  type SortSpec,
} from "@/components/data-grid/data-grid";
import { columns, orders } from "./orders";

type SavedView = {
  sort: SortSpec[];
  filters: FilterNode[];
  search: string;
  layout: ColumnLayout;
};

const VIEW_KEY = "orders-view";

function readView(): Partial<SavedView> {
  try {
    return JSON.parse(localStorage.getItem(VIEW_KEY) ?? "{}");
  } catch {
    return {};
  }
}

function saveView(patch: Partial<SavedView>) {
  const next = { ...readView(), ...patch };
  localStorage.setItem(VIEW_KEY, JSON.stringify(next));
}

export function OrdersGrid() {
  const [view, setView] = useState<Partial<SavedView>>();
  useEffect(() => setView(readView()), []);
  if (!view) return null;

  return (
    <DataGrid className="h-96"
      defaultData={orders}
      columns={columns}
      defaultSortState={view.sort}
      defaultFilterState={view.filters}
      defaultSearchText={view.search}
      defaultColumnLayout={view.layout}
      onSortChange={(sort) => saveView({ sort })}
      onFilterChange={(filters) => saveView({ filters })}
      onSearchTextChange={(search) => saveView({ search })}
      onColumnLayoutChange={(layout) => saveView({ layout })}
    />
  );
}
```

## Result

A reload restores the sort, the filters, the search text, and the width, order, pins, and hidden state of the columns. An `undefined` default leaves that part at its normal start. The grid reads each default once at mount and ignores later changes.

The grid drops a saved layout id that names no column. It drops a saved sort or filter that names no column too, and warns once in development. A new column joins at the end, in the order of `columns`.

## Convert a view saved before 1.3.0

A view saved before gridcn 1.3.0 can hold a `joinOperator`. The filter list has no separate join, so wrap the filters in a group as you read the view:

```ts
import type { FilterNode } from "@/components/data-grid/data-grid";

type OldView = { filters?: FilterNode[]; joinOperator?: "and" | "or" };

export function readFilters(saved: OldView): FilterNode[] | undefined {
  if (saved.joinOperator !== "or" || !saved.filters) return saved.filters;
  return [{ join: "or", filters: saved.filters }];
}
```

The [saved views add-on](/docs/sort-filter-search/saved-views) saves several named views with a picker. To share a view as a link, use [URL state](/docs/sort-filter-search/url-state). To save the view for each user on a server, send the same patches from the callbacks to your API.
