Without a `store` prop, every `DataGrid` and every `DataGridProvider` creates its own store. No module-level store exists, so several grids work on one page with no setup. Sort, filter, selection, edits, and focus stay apart. To link two grids, pass state through React: a callback of one grid sets state, and the other grid reads it.

## Before you start

- Give every row of every grid a stable `id`, or pass `getRowId`.
- Give each grid a height. `className="h-[400px]"` is enough.

## Steps

1. Hold the shared value in state above both grids.
2. Set it from a callback of the first grid. With no active cell, `onActiveCellChange` passes `null`.
3. Derive the rows of the second grid from that state with `useMemo`.
4. Pass the derived rows as `data` to the second grid. For a display-only grid, add `readOnly`.

## Show the orders of the active customer

The sample links a customer grid to an order grid:

```tsx
"use client";

import { useMemo, useState } from "react";
import { DataGrid, defineColumns } from "@/components/data-grid/data-grid";

type Customer = { id: string; name: string };
type Order = { id: string; customerId: string; total: number };

const customerColumns = defineColumns<Customer>()([
  { id: "name", header: "Customer", accessorKey: "name", type: "text" },
] as const);

const orderColumns = defineColumns<Order>()([
  { id: "id", header: "Order", accessorKey: "id", type: "text" },
  { id: "total", header: "Total", accessorKey: "total", type: "number" },
] as const);

type Props = { customers: Customer[]; orders: Order[] };

export function CustomersAndOrders({ customers, orders }: Props) {
  const [customerId, setCustomerId] = useState<string | null>(null);
  const customerOrders = useMemo(
    () => orders.filter((order) => order.customerId === customerId),
    [orders, customerId],
  );

  return (
    <div className="grid grid-cols-2 gap-4">
      <DataGrid
        className="h-[400px]"
        defaultData={customers}
        columns={customerColumns}
        onActiveCellChange={(next) => setCustomerId(next?.rowId ?? null)}
      />
      <DataGrid
        className="h-[400px]"
        data={customerOrders}
        columns={orderColumns}
        readOnly
      />
    </div>
  );
}
```

## Result

The order grid shows the orders of the customer in the active cell. It shows no rows while no cell is active. Each grid keeps its own sort, filter, and selection.

<Callout type="warn" title="Give each grid a URL prefix">
  Two grids that use `data-grid-url-state` use the same keys, such as `sort`, `filter`, and `q`, so their values collide. Set a different `prefix` on each grid. See [URL state](/docs/sort-filter-search/url-state#prefix).
</Callout>
