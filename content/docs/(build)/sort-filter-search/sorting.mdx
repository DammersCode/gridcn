Users order rows by one column or by several. Every grid sorts its `data` by `sortState`. With `headerClickBehavior="sort"`, a header click sets that state. The `data-grid-sort-list` add-on adds a toolbar button with a popover that adds, removes, and reorders sorts without the headers.

The sample below also uses `DataGridToolbar`. Install the [toolbar add-on](/docs/sort-filter-search/toolbar) as well.

This grid sorts from the headers, from the sort list, and from a seeded sort:

```tsx
"use client";

import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  defineColumns,
} from "@/components/data-grid/data-grid";
import { DataGridSortList } from "@/components/data-grid-sort-list/data-grid-sort-list";
import { DataGridToolbar } from "@/components/data-grid-toolbar/data-grid-toolbar";

type Person = { id: string; name: string; age: number };

const columns = defineColumns<Person>()([
  { id: "name", header: "Name", accessorKey: "name" },
  { id: "age", header: "Age", accessorKey: "age", type: "number" },
]);

export function PeopleGrid({ rows }: { rows: Person[] }) {
  return (
    <DataGridProvider
      defaultData={rows}
      columns={columns}
      getRowId={(row) => row.id}
      headerClickBehavior="sort"
      defaultSortState={[{ columnId: "age", direction: "desc" }]}
    >
      <DataGridToolbar>
        <DataGridSortList />
      </DataGridToolbar>
      <DataGridRoot className="h-96">
        <DataGridHeader />
        <DataGridBody />
      </DataGridRoot>
    </DataGridProvider>
  );
}
```

## Sort from the headers [#sorting]

The default `headerClickBehavior` is `"select"`, so a header click selects the column. With `"sort"`, a plain click cycles the column: ascending first, then descending, then no sort. <kbd>Shift</kbd>+click adds the column to the sort. A new column joins at the end, so the first sort stays primary. Another <kbd>Shift</kbd>+click cycles that column in place.

A string header shows a sort arrow on every sorted column, whatever `headerClickBehavior` says. A sort from the sort list or the URL shows the arrow too. In `"sort"` mode, the arrow also shows on a column that is not sorted yet.

`sortable: false` on a column removes it from the header click and from the sort list. Code can still sort it with `actions.setSorts()`. Read the sorts with `useDataGridSortState()`.

## Sort order

The first sort is primary. Each later sort orders only the rows that the earlier sorts leave tied. Rows that tie on every sort keep their original order.

A column compares two rows with the first of these that applies:

1. The column `sortCompare(rowA, rowB)`. A result of `0`, `NaN`, or a thrown error passes the pair to the text compare.
2. The `compare` of the column's declared cell type. Numbers sort by value, dates in date order, and `select` columns by choice label. A `text` column compares with the locale order, so `item10` comes before `item2`.
3. A text compare that ignores case and reads digit runs as numbers, so `item2` comes before `item10`. A column without a `type` uses it.

For numbers, set `type: "number"`. The text compare reads `1.5` as 1 and 5, and it puts negative numbers backwards.

The direction applies to all three. Empty cells sort last in both directions.

## Sort list

`DataGridSortList` belongs in a `DataGridToolbar`. The button shows a count badge once a sort is active. Each row of the popover has a column select, a direction select, a remove button, and a drag handle. A column appears in one row only, and `sortable: false` columns do not appear. The popover also has "Add sort" and "Clear all" buttons.

The list reads and writes the same state as the headers, so both stay in step. The order of the rows is the sort precedence.

| Prop | Type | Default | Description |
|---|---|---|---|
| `allColumns` | `boolean` | `false` | Offers hidden columns too. |
| `className` | `string` | none | Classes for the button. |

### Keyboard & accessibility

| Key | Action |
|---|---|
| <kbd>Tab</kbd> | Moves through a row: column select, direction select, remove button, drag handle. |
| <kbd>ArrowUp</kbd> / <kbd>ArrowDown</kbd> on the drag handle | Moves the sort one place and keeps focus on the handle. |
| <kbd>Backspace</kbd> / <kbd>Delete</kbd> on the drag handle | Removes the sort. Focus moves to the next row's handle, then the previous one, then "Add sort". |

Each move announces the new place through a polite live region. Set the text with `labels.sort.sortReorderAnnouncement`.

## Controlled and initial sort

`defaultSortState` seeds the sort once, and later changes to it have no effect. `sortState` makes the prop the source of truth. `onSortChange(next)` fires on every user change in both cases. A controlled grid reorders its rows only after the `sortState` prop changes.

## Server mode

If your server orders the rows, set `sortMode="server"`. The grid tracks the sort spec and never reorders `data`. The header cycle, `aria-sort`, the sort arrow, the sort list, and `onSortChange` all work as in client mode.

A grid with a `totalRowCount` prop <NewBadge /> defaults `sortMode` to `"server"`, because its `data` holds only part of the result. To sort the rows in `data` in the browser, set `sortMode="client"`.

The request is the `SortSpec[]` that `onSortChange` receives. The answer is the rows, already in that order.

`useDataGridServerRows` sets `sortMode`, `filterMode`, and the controlled sort for you. It passes each fetch the spec as `request.spec.sorts`. Make that order total, because the hook keeps only the first row of a repeated row id. See [Query server rows](/docs/data-modes/query-server-rows) for the full flow.
