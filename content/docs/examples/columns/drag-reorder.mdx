Two paths to the same `columnOrder` state: drag a header (the move is scoped to the header's
pin zone), or call `actions.setColumnOrder(id, targetId, position)` programmatically. The demo
shows both — Name opts out with `reorderable: false`, and Score is pinned right, so it only
moves with the pinned zone.

## What's in the demo

- `enableColumnReorder` — header drag with a drop indicator, grid-wide default `true`
- `reorderable: false` on Name — the per-column opt-out that beats the grid flag
- `pin: "right"` on Score — a drag crossing pin zones is a no-op
- Picker + Left/Right buttons — `setColumnOrder(selectedId, neighborId, "before" | "after")`
  from `useDataGridActions()`, disabled at the order's edges
