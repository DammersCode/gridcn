title: Server Pagination
description: Client slicing vs server mode — and the same server mode through TanStack Query and SWR.
icon: Files
---

`useDataGridPagination` has two modes. Client mode slices a dataset you already hold in
memory. Server mode only does the page math. You own `page`, `pageSize`, `total`, and
fetching the page yourself. The same server mode pairs with any fetch layer: the three pages
below.
