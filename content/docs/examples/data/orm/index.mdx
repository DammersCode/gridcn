The grid's server contract is small: take `{ spec, start, end }`, where `spec` holds `sorts`, `filters`, and `searchText`,
and return `{ rows, totalRowCount }`. That is the request and the answer of `fetchRows` in
[`useDataGridServerRows`](/docs/lazy-loading). These recipes show the contract in three real
stacks. The [server-side example](/docs/examples/data/server-side) calls it with `start` and
`end` taken from the page. The recipes are documentation only. Each one needs a server.
