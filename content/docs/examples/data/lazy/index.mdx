---
title: Lazy Loading
description: Fetch rows only as they scroll into view — a plain fetcher, TanStack Query, and SWR.
icon: Loader
---

`useDataGridLazyRows` keeps a sparse row array and asks for `[start, end)` windows as the
viewport scrolls; skeleton rows hold the space until each window lands. What fills a window
is your choice — a plain fetch, a TanStack Query cache, or SWR's global cache. Each page
embeds the live registry example.
