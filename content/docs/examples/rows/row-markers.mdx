The marker column is pinned left and sits outside the data index space. The built-in modes:
`none`, `number`, `checkbox` (drives the rows selection channel + a select-all header
checkbox), and `both` (row number, replaced by the checkbox on hover/selection). Or replace
the rendering entirely with your own marker/header components.

## What's in the demo

- `rowMarkers` select — switches `none` / `number` / `checkbox` / `both` and the `reorder` family live
- `both` mode — hover a row: the number is replaced by the checkbox while hovered or selected

## Custom markers

The same grid with `renderMarker` / `renderMarkerHeader`: a lucide icon marker reflecting the
row's selection state, and a select-all header button — while the marker cell's own
press/drag gestures still select rows.
