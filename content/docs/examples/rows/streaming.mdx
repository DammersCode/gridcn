A live ticker: `updateCells` streams new values in place, four batches per second. The
**Auto-sort** switch picks how the display reacts — `reorder: "immediate"` re-sorts every tick,
`reorder: "defer"` lets the values land and shows a Re-sort bar when the display order goes
stale.

## What's in the demo

- A ticker feed pushing `change`/`volume` patches for every row every 250 ms
- **Auto-sort** on — the grid re-sorts by the sorted column on every batch (watch the rows
  shuffle as prices cross each other)
- **Auto-sort** off — rows hold their position; when a deferred batch changed the sort order a
  Re-sort bar appears, and `reconcileView()` applies it in one step
