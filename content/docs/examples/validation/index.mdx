Validation in four forms: synchronous rules as a plain function or a Standard Schema library
column (Zod, Joi, Valibot), async checks with a visible pending state, server-side rejections
painted after commit, and cross-field rules via `validateRow`. Each page embeds the live
registry example; the [editing guide](/docs/editing-cell-types#validation) has the full
reference.
