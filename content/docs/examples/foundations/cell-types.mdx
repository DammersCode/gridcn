One column per built-in cell type, plus the three most common column-level overrides: `readOnly`,
a sync `validate` rule, and a `renderCell` display override that keeps the type's full
edit/sort/clipboard pipeline.

## What's in the demo

- `text` — plain strings, the default type
- `text` + `readOnly: true` — displays, refuses edits
- `number` + `options: { min, max }` — clamped input
- `number` + `validate` — rejects values under 18, keeps the editor open with the message
- `checkbox`, `select` (choices), `date` (`displayFormat`)
- `number` + `renderCell` — renders a progress bar. Editing, pasting, and sorting still run the
  number type's pipeline
