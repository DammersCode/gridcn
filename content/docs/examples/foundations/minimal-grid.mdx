The smallest working grid: one registry item, `defaultData`, and no app-side state. The grid
owns its rows internally — you only reach for `data` + `onDataChange` when you need to persist,
fetch, or react to edits.

## What's in the demo

- `<DataGrid>` convenience wrapper — header, body, and viewport composed for you
- `defineColumns` with three built-in types: `text`, `number`, `checkbox`
- `defaultData` — seed rows with no `data`/`onDataChange` wiring
- `getRowId` — stable row identity from the data itself
- `className` — the grid takes a CSS box; here `w-full h-[240px]`
