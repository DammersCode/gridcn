Before you start, [install the core grid](/docs/learning-path/install-gridcn).

This step renders a grid with three columns and three rows. You can edit every cell.

## Add the columns [#define-columns]

A column maps one field of a row to one grid column.

- `accessorKey` names the row field that the column reads.
- `type` names the cell type: the kind of value the column holds. It sets how the cell renders and edits.
- `id` identifies the column.

`defineColumns<Person>()` is two calls. The first fixes the row type. The second infers the value type of each column. Add this file:

```tsx title="columns.ts"
import { defineColumns } from "@/components/data-grid/data-grid";

export type Person = { id: string; name: string; age: number; active: boolean };

export const columns = defineColumns<Person>()([
  { id: "name", header: "Name", accessorKey: "name", type: "text" },
  { id: "age", header: "Age", accessorKey: "age", type: "number" },
  { id: "active", header: "Active", accessorKey: "active", type: "checkbox" },
]);
```

## Render the grid [#render-the-grid]

`defaultData` seeds the grid once. After the first render the grid owns the rows, so edits, pastes, and deletes need no state in your code. Add this file and render `<PeopleGrid />` on any page:

```tsx title="people-grid.tsx"
"use client";

import { DataGrid } from "@/components/data-grid/data-grid";
import { columns, type Person } from "./columns";

const people: Person[] = [
  { id: "1", name: "Ada Lovelace", age: 28, active: true },
  { id: "2", name: "Grace Hopper", age: 34, active: true },
  { id: "3", name: "Margaret Hamilton", age: 31, active: false },
];

export function PeopleGrid() {
  return <DataGrid defaultData={people} columns={columns} className="h-96" />;
}
```

`className="h-96"` gives the grid a fixed height. Without a bounded height the grid cannot virtualize. It draws at most 200 rows and, when more than 200 rows fit, warns once in development. In a flex column or a CSS grid track, give the grid `min-h-0 flex-1` or `h-full min-h-0` instead. Without `min-h-0`, a flex or grid item grows to fit every row.

To keep the rows in your own state, see [Keep edits in your state](/docs/learning-path/keep-edits-state).

## Row ids

`getRowId` returns the id of a row. It defaults to the `id` field of the row. The field must be a string or a number. Otherwise the grid throws an error that asks for `getRowId`. If the id lives in another field, such as `name` here, pass `getRowId`:

```tsx fragment="a prop of the grid, not a full file"
<DataGrid
  defaultData={people}
  columns={columns}
  getRowId={(person) => person.name}
/>
```

Each id must be stable and unique. Selection, edit sessions, and undo address rows by row id. If you change what `getRowId` returns, pass a new `data` array in the same render. Otherwise development mode warns.

## Try it

Click a cell, then use these keys:

- In the Name and Age columns, type a character to replace the value of the cell.
- In the same columns, press <kbd>F2</kbd>, <kbd>Enter</kbd>, or <kbd>Space</kbd> to edit the value in place. A double-click does the same.
- In the Active column, a click on the box, <kbd>Space</kbd>, or <kbd>Enter</kbd> toggles the checkbox. Typing does nothing there.
- While you edit, press <kbd>Enter</kbd> to commit and move down. Press <kbd>Escape</kbd> to cancel.
- Press <kbd>Delete</kbd> to empty the selected cells.

A click on a column header selects the whole column. It does not sort. To sort on a header click, see [Sort and filter rows](/docs/learning-path/sort-filter-rows).

## DataGrid is shorthand [#datagrid-is-shorthand]

`<DataGrid>` renders `DataGridProvider`, `DataGridRoot`, `DataGridHeader`, and `DataGridBody`. To place a toolbar above the grid, compose the parts yourself: the toolbar goes inside `DataGridProvider`, before `DataGridRoot`.
