Each add-on has an options page. It lists the hook options or component props, the result, and the limits. The behavior of the add-on lives on its feature page.

## Clipboard and undo

- [Fill handle options](/docs/add-options/clipboard-undo/fill-handle-options): `useDataGridFill`, `FillArgs`, and the series descriptor.
- [Undo and redo options](/docs/add-options/clipboard-undo/undo-redo-options): `useDataGridHistory` and `useDataGridState`.

## Import and export

- [Import options](/docs/add-options/import-export/import-options): import defaults and limits, the dialog props, and the functions for a custom import.
- [Export options](/docs/add-options/import-export/export-options): `exportGrid`, `buildXlsx`, `printGrid`, and the export and print buttons.

## Rows, pages, and menus

- [Context menu options](/docs/add-options/rows-pages-menus/context-menu-options): `DataGridContextMenu` and `DataGridHeaderDropdown`.
- [Client pagination options](/docs/add-options/rows-pages-menus/client-pagination-options): `useDataGridPagination` and `DataGridPaginationBar`.
- [Pinned rows options](/docs/add-options/rows-pages-menus/pinned-rows-options): `useDataGridPinnedRows` and `useDataGridAggregate`.

## Selection and shortcuts

- [Shortcut remapping options](/docs/add-options/selection-shortcuts/shortcut-remapping-options): the keymap and commands props and the shortcuts dialog.
- [Status bar options](/docs/add-options/selection-shortcuts/status-bar-options): `DataGridStatusBar` and `useDataGridSelectionStats`.

## Server

- [Server rows options](/docs/add-options/server/server-rows-options): `useDataGridServerRows` in pages mode and scroll mode.
- [Presence options](/docs/add-options/server/presence-options): `useDataGridPresence` and the highlight shapes.

## Sort, filter, and search

- [Toolbar options](/docs/add-options/sort-filter-search/toolbar-options): the toolbar, search, filter menu, columns menu, and header filter.
- [Sort list options](/docs/add-options/sort-filter-search/sort-list-options): `DataGridSortList`.
- [Find and replace options](/docs/add-options/sort-filter-search/find-replace-options): `useDataGridFindReplace` and `planReplace`.
- [URL state options](/docs/add-options/sort-filter-search/url-state-options): `DataGridUrlState` and the URL pagination hook.
