A `lookup` column takes a `LookupOptions` object in its `options` field. You must pass `fetchOptions`. The other options have defaults. The editor, the stored value, and the clipboard rules are on [Lookup cell](/docs/editing-cells/lookup-cell).

| Type | Holds |
| --- | --- |
| [`LookupOptions`](#lookupoptions) | The column options of the cell type. |
| [`LookupFetchRequest`](#lookupfetchrequest) | The argument of `fetchOptions`. |
| [`LookupLabels`](#lookuplabels) | The text of the editor. |
| [`LookupOption`, `LookupValue`](#lookupvalue) | One option, and the value a cell stores. |

## LookupOptions [#lookupoptions]

{/* props: LookupOptions */}

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `fetchOptions` | `(request: LookupFetchRequest) => Promise<readonly LookupOption[]>` | required | Resolves the options that match `query`. |
| `debounceMs` | `number` | the grid's `inputDebounceMs` | The wait after the last keystroke before a request starts. |
| `minQueryLength` | `number` | `0` | The fewest typed characters that start a request. With `0`, an opened editor loads the default list. |
| `maxResults` | `number` | `50` | The most options that the editor shows. The editor uses at most `200`. |
| `unresolvedPaste` | `"clear" \| "keep"` | `"clear"` | The result of a pasted or imported text that matches no known option. `"clear"` empties the cell. `"keep"` stores `{ value: text, label: "" }` with the trimmed text, which shows as unresolved. |
| `labels` | `Partial<LookupLabels>` | English | The text of the editor. Each field that you leave out stays English. |

Keep `fetchOptions` stable: define it outside the render, or memoize it. The cell type resolves a pasted label through a cache that belongs to the `fetchOptions` function. The cache holds at most 5,000 labels and drops the oldest first.

The editor treats the answer of `fetchOptions` as untrusted input:

- The editor reads an array only. Any other answer and a rejected promise show the error line with the Retry button.
- If `value` is a non-empty text or a finite number and `label` is a text, the editor keeps the entry. A number `value` becomes text.
- An empty `label` shows the `value`.
- The editor drops a repeated `value`, cuts `value` and `label` at 256 characters, and keeps the first `maxResults` entries.

## LookupFetchRequest [#lookupfetchrequest]

{/* props: LookupFetchRequest */}

| Prop | Type | Description |
| --- | --- | --- |
| `query` | `string` | The text that the user typed. `""` asks for the default list. The search box holds at most 256 characters. |
| `signal` | `AbortSignal` | If the user types again, closes the editor, or the cell unmounts, the signal aborts. Pass it to `fetch`. |
| `row` <NewBadge /> | `unknown` | The row that the user edits. A dependent lookup reads it, such as a city list for the country of the row. Narrow the type in your callback. |
| `rowId` <NewBadge /> | `string` | The id of that row. |
| `columnId` <NewBadge /> | `string` | The id of the lookup column. |

The request does not repeat when a push changes the row during the edit.

The editor drops an answer that arrives after its signal aborted.

## LookupLabels [#lookuplabels]

{/* props: LookupLabels */}

| Prop | Type | English text |
| --- | --- | --- |
| `searching` | `string` | `"Searching…"` |
| `noResults` | `string` | `"No results"` |
| `error` | `string` | `"Could not load options"` |
| `retry` | `string` | `"Retry"` |
| `typeMore` | `(missing: number) => string` | `"Type 2 more characters"` for `2` |

`typeMore` receives the number of characters that `minQueryLength` still asks for.

## LookupOption and LookupValue [#lookupvalue]

`LookupOption` is `{ value: string; label: string }`. `value` is the key that your server uses. `label` is the text that the grid shows, copies, sorts, searches, and filters.

`LookupValue` is the value that a cell stores: a `LookupOption`, a bare key string without a label, or `null`. A bare key, or an option with an empty `label`, shows in muted text with a `data-unresolved` attribute until the user picks an option.

## Example

This sample asks for three characters before a search and sets the labels in German:

```tsx
import type { LookupOptions } from "@/components/data-grid-lookup/data-grid-lookup";

export const customerOptions: LookupOptions = {
  fetchOptions: async ({ query, signal }) => {
    const url = `/api/customers?q=${encodeURIComponent(query)}`;
    const res = await fetch(url, { signal });
    return res.json();
  },
  minQueryLength: 3,
  maxResults: 20,
  labels: {
    searching: "Suche…",
    noResults: "Keine Treffer",
    typeMore: (missing) => `Noch ${missing} Zeichen`,
  },
};
```
