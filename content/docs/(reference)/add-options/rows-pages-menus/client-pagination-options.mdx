`useDataGridPagination` takes `data` and returns the rows of the current page with a `pager`. A grid pages its view with `pageSize` on `DataGridProvider`, and `useDataGridPager()` returns `{ pager }`. `DataGridPaginationBar` renders the footer from the pager. The behavior, how sort, filter, and search cover every page, and the install steps are on [Client pagination](/docs/rows-pages-menus/client-pagination).

## Client options [#client-mode]

The hook slices `data` into pages for a list that is not a grid. To page a grid, set `pageSize` or `defaultPageSize` on `DataGridProvider` instead, as [Page the grid](/docs/rows-pages-menus/client-pagination#client-mode) shows.

<AutoTypeTable path="./registry/default/blocks/data-grid-pagination/use-data-grid-pagination.ts" name="UseDataGridPaginationClientOptions" />

`pageSizeOptions` defaults to `[10, 25, 50, 100]`. Without `defaultPageSize`, the first size of `pageSizeOptions` applies. The page and the page size stay uncontrolled until you pass `page` or `pageSize`. A page-size change moves to the page that holds the first row of the current page.

## Server pager

`useDataGridServerPager({ page, pageSize, totalRowCount, hasMore, onPageChange, pageSizeOptions, onPageSizeChange })` returns `{ pager }` for rows that you fetch yourself. `totalRowCount` is a number, or `null` for an unknown size. `hasMore` is read only while `totalRowCount` is `null`. Without `onPageSizeChange`, the bar hides the page-size select. Its other options are on [Server rows options](/docs/add-options/server/server-rows-options#pager-options). Its options type is `UseDataGridServerPagerOptions`.

## Grid pager

`useDataGridPager({ pageSizeOptions })` returns `{ pager }` for a grid that pages its view. Call it under `DataGridProvider`. `DataGridPaginationBar` with no props calls it for you. Its options type is `UseDataGridPagerOptions`.

## DataGridPaginationBar [#datagridpaginationbarprops]

Spread the `pager` onto the bar. Inside a paged `DataGridProvider`, pass no pager and the bar reads the grid.

<AutoTypeTable path="./registry/default/blocks/data-grid-pagination/pagination-footer.tsx" name="DataGridPaginationBarProps" />

The root element carries the `data-grid-pagination` attribute. `labels` merges over the `labels.pagination` of the enclosing grid, or over the `labels.pagination` defaults outside a `DataGridProvider`.

## Footer parts [#parts]

Without `children`, the bar renders the range, the page-size select, and the first, previous, pages, next, and last controls. Pass `children` to arrange the parts yourself. Every part reads the pager from the bar. A part outside a bar throws.

| Part | Renders |
| --- | --- |
| `DataGridPaginationRange` | The range label, the empty label, or "Page 3" when the count is `null` |
| `DataGridPaginationPageSize` | The rows-per-page select |
| `DataGridPaginationFirst` | A button to page 1, disabled on page 1 |
| `DataGridPaginationPrev` | A button to the previous page, disabled on page 1 |
| `DataGridPaginationPages` | The numbered buttons, `windowSize` at a time (default 5). The props type is `DataGridPaginationPagesProps`. |
| `DataGridPaginationNext` | A button to the next page, disabled without a next page |
| `DataGridPaginationLast` | A button to the last page, disabled on the last page and while the count is unknown |

This sample builds a compact footer:

```tsx
import {
  DataGridPaginationBar,
  DataGridPaginationNext,
  DataGridPaginationPrev,
  DataGridPaginationRange,
  useDataGridPagination,
} from "@/components/data-grid-pagination/data-grid-pagination";

export function CompactPager({ rows }: { rows: { id: string }[] }) {
  const { pageData, pager } = useDataGridPagination({
    data: rows,
    defaultPageSize: 25,
  });
  return (
    <>
      <p>{pageData.length} rows on this page</p>
      <DataGridPaginationBar {...pager}>
        <DataGridPaginationRange />
        <div className="flex items-center gap-1">
          <DataGridPaginationPrev />
          <DataGridPaginationNext />
        </div>
      </DataGridPaginationBar>
    </>
  );
}
```
