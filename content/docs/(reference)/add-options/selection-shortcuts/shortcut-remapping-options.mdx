## Binding strings [#binding-strings]

A binding is a string of modifiers and one key, joined with `+`, for example `"mod+shift+ArrowUp"`. A `keymap` entry maps an action to an array of bindings.

| Modifier | Matches |
| --- | --- |
| `mod` | <kbd>Cmd</kbd> on macOS, iOS, and iPadOS. <kbd>Ctrl</kbd> elsewhere. |
| `ctrl` | The physical <kbd>Ctrl</kbd> key on every platform. |
| `shift` | <kbd>Shift</kbd> |
| `alt` | <kbd>Alt</kbd> or <kbd>Option</kbd> |

The key is a letter, a digit, a function key `F1` to `F24`, a named key, or a printable character. The typed named keys are `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Escape`, `Tab`, `Backspace`, and `Delete`. Other stable key names, such as `Insert` or `MediaPlayPause`, bind the same way, in exact case. Write a letter in lowercase, and it matches in either case. Write the space bar as a literal space. The last `+` separates the key, so the plus key cannot bind.

The modifiers of the key event must equal the modifiers of the binding. The exception is a punctuation key such as `?` or `/`: without `shift` in the binding, <kbd>Shift</kbd> is ignored. A binding that names `shift` requires it, and wins over a binding without it. A binding with an unknown modifier never matches. A binding with an unknown modifier or key name warns in the browser console in development.

## Keymap

`keymap` has the type `Keymap`, a partial map from action to `KeyBinding[]`. The grid merges it over `DEFAULT_KEYMAP`.

- An action you leave out keeps its default bindings.
- An action with an array replaces the default bindings.
- An action with an empty array has no binding.
- A defined `typeToReplace` entry, even an empty one, turns off the implicit printable-key trigger.

## Reserved chords [#reserved-chords]

The OS or the browser owns some key combinations. A binding on one of them never fires, or the browser acts on the key too. Do not bind these chords:

| Chord | Owner |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd> with any key | Windows reads it as <kbd>AltGr</kbd>. On a German layout, <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Q</kbd> types `@`, so a `mod+alt+q` or `ctrl+alt+q` binding never fires there. The grid matches the typed character, so only a binding on that character, such as `mod+alt+@`, fires. |
| <kbd>Cmd</kbd>+<kbd>Space</kbd> | macOS Spotlight. |
| <kbd>Ctrl</kbd>+<kbd>Space</kbd> | Toggles the IME on Windows Chinese layouts and switches the input source on macOS. The default `selectColumn` binding uses it. |
| `mod+shift+u` | Starts Unicode entry in GTK and IBus on Linux. The default `insertRowAbove` binding uses it. |
| <kbd>Ctrl</kbd>+<kbd>Option</kbd> with any key | VoiceOver on macOS, while it runs. For example, <kbd>Ctrl</kbd>+<kbd>Option</kbd>+<kbd>Space</kbd> activates an item. |
| `mod` with <kbd>+</kbd>, <kbd>-</kbd>, or <kbd>=</kbd> | Browser zoom. The page cannot stop it. |
| `mod+shift` with <kbd>I</kbd>, <kbd>J</kbd>, <kbd>C</kbd>, <kbd>K</kbd>, or <kbd>E</kbd> | Developer tools. <kbd>E</kbd> opens them in Firefox and Edge. |
| `mod+shift` with <kbd>D</kbd>, <kbd>M</kbd>, <kbd>N</kbd>, or <kbd>Delete</kbd> | Browser bookmarks, profiles, a private window, and the dialog that clears browsing data. |
| `mod` with <kbd>N</kbd>, <kbd>T</kbd>, or <kbd>W</kbd>, `mod+shift` with <kbd>T</kbd> or <kbd>W</kbd>, and <kbd>Ctrl</kbd>+<kbd>Tab</kbd> | Browser windows and tabs. Chrome keeps these keys and never sends them to the page, so `preventDefault` cannot stop them. |

## BindingChips [#bindingchips]

`BindingChips` renders one keycap for each token of a binding. On the server it renders word names. On macOS, iOS, and iPadOS it switches to glyphs after hydration.

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `binding` | `string` | required | Sets the binding to render, such as `"mod+c"`. |
| `className` | `string` | none | Merges into the class list of the keycap group. |

## Example

This sample opens the dialog on <kbd>?</kbd> and adds a second select-all binding:

```tsx
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  defineColumns,
} from "@/components/data-grid/data-grid";
import {
  useDataGridKeybindings,
} from "@/components/data-grid-keybindings/data-grid-keybindings";

type Row = { id: string; name: string };

const rows: Row[] = [{ id: "1", name: "Ada" }];
const columns = defineColumns<Row>()([
  { id: "name", header: "Name", accessorKey: "name" },
]);

export function ShortcutsGrid() {
  const keys = useDataGridKeybindings();
  return (
    <DataGridProvider
      defaultData={rows}
      columns={columns}
      keymap={{ selectAll: ["mod+a", "F8"] }}
      plugins={[keys.plugin]}
    >
      <DataGridRoot className="h-80">
        <DataGridHeader />
        <DataGridBody />
      </DataGridRoot>
    </DataGridProvider>
  );
}
```
