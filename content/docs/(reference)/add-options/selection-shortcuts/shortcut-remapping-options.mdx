The `keymap` and `commands` props of `DataGridProvider` set the key bindings of a grid. The `data-grid-keybindings` add-on shows them. The steps and the behavior are on [Shortcut remapping](/docs/selection-shortcuts/shortcut-remapping).

## Binding strings [#binding-strings]

A binding is a string of modifiers and one key, joined with `+`, for example `"mod+shift+ArrowUp"`. A `keymap` entry maps an action to an array of bindings.

| Modifier | Matches |
| --- | --- |
| `mod` | <kbd>Cmd</kbd> on macOS, iOS, and iPadOS. <kbd>Ctrl</kbd> elsewhere. |
| `ctrl` | The physical <kbd>Ctrl</kbd> key on every platform. |
| `shift` | <kbd>Shift</kbd> |
| `alt` | <kbd>Alt</kbd> or <kbd>Option</kbd> |

The key is a letter, a digit, a function key `F1` to `F24`, a named key, or a printable character. The typed named keys are `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Home`, `End`, `PageUp`, `PageDown`, `Enter`, `Escape`, `Tab`, `Backspace`, and `Delete`. Other stable key names, such as `Insert` or `MediaPlayPause`, bind the same way, in exact case. Write a letter in lowercase, and it matches in either case. Write the space bar as a literal space. The last `+` separates the key, so the plus key cannot bind.

The modifiers of the key event must equal the modifiers of the binding. The exception is a punctuation key such as `?` or `/`: without `shift` in the binding, <kbd>Shift</kbd> is ignored. A binding that names `shift` requires it, and wins over a binding without it. A binding with an unknown modifier never matches. A binding with an unknown modifier or key name warns in the browser console in development.

## Keymap

`keymap` has the type `Keymap`, a partial map from action to `KeyBinding[]`. The grid merges it over `DEFAULT_KEYMAP`.

- An action you leave out keeps its default bindings.
- An action with an array replaces the default bindings.
- An action with an empty array has no binding.
- A defined `typeToReplace` entry, even an empty one, turns off the implicit printable-key trigger.

## BindingChips

`BindingChips` takes a `binding` string and renders one keycap for each token. On the server it renders word names. On macOS, iOS, and iPadOS it switches to glyphs after hydration.

## Example

This sample opens the dialog on <kbd>?</kbd> and adds a second select-all binding:

```tsx
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  defineColumns,
} from "@/components/data-grid/data-grid";
import { useDataGridKeybindings } from "@/components/data-grid-keybindings/data-grid-keybindings";

type Row = { id: string; name: string };

const rows: Row[] = [{ id: "1", name: "Ada" }];
const columns = defineColumns<Row>()([
  { id: "name", header: "Name", accessorKey: "name" },
]);

export function ShortcutsGrid() {
  const keys = useDataGridKeybindings();
  return (
    <DataGridProvider
      defaultData={rows}
      columns={columns}
      keymap={{ selectAll: ["mod+a", "F8"] }}
      plugins={[keys.plugin]}
    >
      <DataGridRoot className="h-80">
        <DataGridHeader />
        <DataGridBody />
      </DataGridRoot>
    </DataGridProvider>
  );
}
```
