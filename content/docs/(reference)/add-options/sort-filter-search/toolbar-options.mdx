The toolbar add-on exports five components. `DataGridToolbar` is the frame. `DataGridSearch`, `DataGridFilterMenu`, and `DataGridColumnsMenu` sit inside it. `DataGridHeaderFilter` mounts in the header through the `renderHeaderFilter` slot.

| Component | Purpose | Guide |
| --- | --- | --- |
| [`DataGridToolbar`](#datagridtoolbar) | Lays out the toolbar slots | [Toolbar](/docs/sort-filter-search/toolbar) |
| [`DataGridSearch`](#datagridsearch) | Quick search input | [Quick search](/docs/sort-filter-search/quick-search) |
| [`DataGridFilterMenu`](#datagridfiltermenu) | Filter popover | [Filtering](/docs/sort-filter-search/filtering) |
| [`DataGridColumnsMenu`](#datagridcolumnsmenu) | Shows and hides columns | [Toolbar](/docs/sort-filter-search/toolbar) |
| [`DataGridHeaderFilter`](#datagridheaderfilter) | Value list in a column header | [Header filter](/docs/sort-filter-search/header-filter) |

`DataGridToolbar`, `DataGridSearch`, `DataGridFilterMenu`, `DataGridColumnsMenu`, and `DataGridHeaderFilter` <NewBadge /> accept `className`. `DataGridHeaderFilter` merges it into its button. Import the components from `@/components/data-grid-toolbar/data-grid-toolbar`:

```tsx
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  type ColumnDef,
} from "@/components/data-grid/data-grid";
import {
  DataGridColumnsMenu,
  DataGridFilterMenu,
  DataGridHeaderFilter,
  DataGridSearch,
  DataGridToolbar,
} from "@/components/data-grid-toolbar/data-grid-toolbar";

type Person = { id: string; name: string };

const data: Person[] = [{ id: "1", name: "Ada" }];
const columns: ColumnDef<Person>[] = [
  { id: "name", accessorKey: "name", header: "Name" },
];

export function PeopleGrid() {
  return (
    <DataGridProvider data={data} columns={columns} getRowId={(row) => row.id}>
      <DataGridToolbar>
        <DataGridSearch debounceMs={300} />
        <DataGridFilterMenu allColumns />
        <DataGridColumnsMenu />
      </DataGridToolbar>
      <DataGridRoot
        renderHeaderFilter={(ctx) => <DataGridHeaderFilter {...ctx} />}
      >
        <DataGridHeader />
        <DataGridBody />
      </DataGridRoot>
    </DataGridProvider>
  );
}
```

### focusSearch [#focussearch]

<NewBadge />

The `focusSearch` action of the `keymap` prop binds <kbd>Mod</kbd>+<kbd>F</kbd> by default. While focus is inside this grid or its toolbar, the key focuses the input and leaves the browser find bar closed. On macOS, <kbd>Cmd</kbd>+<kbd>F</kbd> and <kbd>Ctrl</kbd>+<kbd>F</kbd> both do this. Focus anywhere else keeps the browser behavior. The handler skips a key press that another handler already handled. `keymap={{ focusSearch: [] }}` leaves the key to the browser.

## DataGridFilterMenu [#datagridfiltermenu]

<AutoTypeTable path="./registry/default/blocks/data-grid-toolbar/filter-menu.tsx" name="DataGridFilterMenuProps" />

### Operator list [#operator-list]

The menu picks the operator list of a column in this order:

1. The `filterOperators` of the column.
2. The `filter.operators` of the cell type.
3. The default list for the column type.

### allColumns [#allcolumns]

Without `allColumns`, the field select offers the visible columns. A filter on a hidden column keeps applying, and its row shows that column with its own operators. <NewBadge />

## DataGridColumnsMenu [#datagridcolumnsmenu]

<AutoTypeTable path="./registry/default/blocks/data-grid-toolbar/columns-menu.tsx" name="DataGridColumnsMenuProps" />

The menu shows and hides columns. It has no pin controls.

## DataGridHeaderFilter [#datagridheaderfilter]

<AutoTypeTable path="./registry/default/blocks/data-grid-toolbar/header-filter.tsx" name="DataGridHeaderFilterProps" />

Spread the context of the `renderHeaderFilter` slot into the component. The slot passes `column` and `index`. `className` <NewBadge /> adds classes to the trigger button. For example, a darker trigger:

```tsx
renderHeaderFilter={(ctx) => <DataGridHeaderFilter {...ctx} className="text-foreground" />}
```

## Server mode

Without `fetchFilterValues`, the value list of `DataGridHeaderFilter` and the `isAnyOf` and `isNoneOf` inputs of a column without `choices` read the loaded rows. Pass `fetchFilterValues` to `DataGridProvider` to read the values from your server. The [header filter page](/docs/sort-filter-search/header-filter) describes the request.
