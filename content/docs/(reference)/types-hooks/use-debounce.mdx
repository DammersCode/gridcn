Typing fires a change on every key. `useDebounce` returns a copy of a value that follows the value only after the value stays the same for a wait. The hook does not depend on the grid.

<InstallCommand item="use-debounce" />

The item installs to `components/gridcn/use-debounce.ts`. The same file holds [`useDebouncedInput`](/docs/types-hooks/use-debounced-input).

## useDebounce [#usedebounce]

```ts fragment="signature"
function useDebounce<T>(value: T, delayMs?: number): T;
```

Debounce a state value before it feeds a request:

```tsx
import { useState } from "react";
import { useDebounce } from "@/components/gridcn/use-debounce";

export function SearchBox() {
  const [query, setQuery] = useState("");
  const debouncedQuery = useDebounce(query, 300);
  return (
    <>
      <input value={query} onChange={(e) => setQuery(e.target.value)} />
      <p>Searching for {debouncedQuery}</p>
    </>
  );
}
```

The input shows each keystroke at once. The line below it changes 300 ms after the last keystroke.

## Arguments [#arguments]

| Argument | Type | Default |
| --- | --- | --- |
| `value` | `T` | Required |
| `delayMs` | `number` | `300` |

## Behavior [#behavior]

- The first render returns `value`.
- Each change of `value` or `delayMs` restarts the wait.
- An unmount cancels a pending update.
- With a `delayMs` of `0` or less, the hook returns `value` itself and sets no timer.

## inputDebounceMs [#inputdebouncems]

The grid waits for typing in its own text inputs through [`useDebouncedInput`](/docs/types-hooks/use-debounced-input). [Quick search](/docs/sort-filter-search/quick-search#typing-delay) describes the `inputDebounceMs` prop.
