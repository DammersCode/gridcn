Each row is a method of `DataGridActions`. `useDataGridActions()` and `api.actions` return the same object. An action with a `CellRef` takes a row id and a column id. A variant that ends in `At` takes a `ViewCoord`, a position in view indexes.

| Action | Purpose | Page |
| --- | --- | --- |
| `applyCellUpdates` | Writes values at view coordinates as one change with the given `source`, and selects the touched cells. | [Data change events](/docs/events-state/data-change-events) |
| `autosizeColumns` | Sizes columns to their content over the whole view and returns the measured widths. | [Column sizing](/docs/columns/column-sizing) |
| `cancelEditing` | Discards the open edit. It writes nothing. | [Edit and validation events](/docs/events-state/edit-validation-events) |
| `checkRowRange` | Checks or unchecks the rows from the anchor row to a target view index. | [Checked rows](/docs/selection-shortcuts/checked-rows) |
| `clearCellErrors` | Clears the cell errors of `targets`. Without `targets`, it clears every cell error. | [Show errors on cells](/docs/save-server/show-errors-cells) |
| `clearCellSelection` | Clears the cell ranges and the column selection, and keeps the checked rows. | [Selection model](/docs/concepts/selection-model) |
| `clearSaveStatus` | Drops the `"failed"` mark of each row whose save the server refused. A row that is still `"saving"` keeps its mark. | [Handle refused saves](/docs/save-server/handle-refused-saves) |
| `clearSelection` | Clears the cell ranges, the column selection, and the checked rows. | [Checked rows](/docs/selection-shortcuts/checked-rows) |
| `commitCellEdit` | Validates and commits the open edit. A refused value keeps the editor open. A commit moves the active cell by `movement`. | [Edit and validation events](/docs/events-state/edit-validation-events) |
| `commitCellValue` | Validates and writes a value at a `CellRef` without an edit session, as a checkbox does. | [Cell type model](/docs/concepts/cell-type-model) |
| `commitCellValueAt` | Takes a `ViewCoord` in place of the `CellRef` of `commitCellValue`. | [Cell type model](/docs/concepts/cell-type-model) |
| `commitChange` | Applies a whole `DataChange` in one write and fires `onDataChange` once. | [Data change events](/docs/events-state/data-change-events) |
| `commitColumnWidth` | Sets a column width and fires `onColumnLayoutChange` once, as a resize release does. | [Column sizing](/docs/columns/column-sizing) |
| `deleteRows` | Deletes the rows at the given view indexes, as one change. | [Row operations](/docs/rows-pages-menus/row-operations) |
| `deleteRowsById` | Deletes the rows with the given ids, as one change. The grid skips an id that matches no row. | [Row operations](/docs/rows-pages-menus/row-operations) |
| `deleteSelection` | Clears every editable cell of the selection to its empty value, as one change. | [Global shortcuts](/docs/selection-shortcuts/global-shortcuts) |
| `duplicateRows` | Duplicates the rows at the given view indexes through `duplicateRow`, as one change. | [Row operations](/docs/rows-pages-menus/row-operations) |
| `extendSelection` | Grows or shrinks the main range by one cell in a direction, or moves its edge to the edge of the view with `toEdge`. | [Keyboard navigation](/docs/selection-shortcuts/keyboard-navigation) |
| `extendTo` | Extends the selection to the cell named by the stable `CellRef`. | [Selection model](/docs/concepts/selection-model) |
| `extendToAt` | Takes a `ViewCoord` in place of the `CellRef` of `extendTo`. | [Selection model](/docs/concepts/selection-model) |
| `flashCells` | Plays the fade pulse on the given cells. It is not a data change. | [Read a push verdict](/docs/rows-live-data/read-push-verdict#flash-cells) |
| `insertRow` | Inserts one row from `createRow` above or below a view index. | [Row operations](/docs/rows-pages-menus/row-operations) |
| `insertRows` | Inserts `count` rows from `createRow` above or below a view index, as one change. | [Row operations](/docs/rows-pages-menus/row-operations) |
| `moveRowsBy` | Shifts rows by `delta` and keeps the gaps between them. Returns whether rows moved. | [Row order](/docs/rows-pages-menus/row-order) |
| `pushRange` | Adds a new range at a `CellRef`, as a Ctrl or Cmd click does. | [Selection model](/docs/concepts/selection-model) |
| `pushRangeAt` | Takes a `ViewCoord` in place of the `CellRef` of `pushRange`. | [Selection model](/docs/concepts/selection-model) |
| `reconcileView` | Rebuilds the view index that a deferred `updateCells` postponed, and clears `viewStale`. | [Stream updates](/docs/rows-live-data/stream-updates) |
| `reorderRows` | Moves rows as one block to a view index. Returns whether rows moved. | [Row order](/docs/rows-pages-menus/row-order) |
| `replaceRowId` | Swaps the id of a row for the id that the server assigned, in one write. | [Save edits](/docs/save-server/save-edits) |
| `replaceRowIds` | Swaps the ids of many rows in one write, with one `onDataChange`. | [Save edits](/docs/save-server/save-edits) |
| `resetColumnWidth` | Drops the width override of a column, so the column gets its `width` from the definition again. | [Column sizing](/docs/columns/column-sizing) |
| `selectAll` | Runs one step of the select-all shortcut. The first call selects the filled block around the active cell, and a repeat selects every cell. | [Global shortcuts](/docs/selection-shortcuts/global-shortcuts) |
| `selectAllMatching` | Checks every row of the result, loaded or not. | [Select server rows](/docs/rows-live-data/select-server-rows) |
| `selectCell` | Selects the cell named by the stable `CellRef` as a single-cell selection. | [Selection model](/docs/concepts/selection-model) |
| `selectCellAt` | Takes a `ViewCoord` in place of the `CellRef` of `selectCell`. | [Selection model](/docs/concepts/selection-model) |
| `selectColumn` | Selects the column at a view column index, as a click on its header does. | [Pointer selection](/docs/selection-shortcuts/pointer-selection) |
| `selectRow` | Selects the row at a view index, as a click on its row marker does. | [Row markers](/docs/rows-pages-menus/row-markers) |
| `setActiveCell` | Moves only the active cell to a `CellRef` and keeps the selection. `null` clears it. Fires no `onSelectionChange`. | [Selection model](/docs/concepts/selection-model) |
| `setActiveCellAt` | Takes a `ViewCoord` in place of the `CellRef` of `setActiveCell`. | [Selection model](/docs/concepts/selection-model) |
| `setAllRowsSelected` | Checks or unchecks every row of the view, as the header checkbox does. | [Checked rows](/docs/selection-shortcuts/checked-rows) |
| `setCellErrors` | Merges server errors into the cell errors. It is not a data change. | [Show errors on cells](/docs/save-server/show-errors-cells) |
| `setColumnHidden` | Shows or hides a column. | [Column visibility](/docs/columns/column-visibility) |
| `setColumnLayout` | Applies a partial `ColumnLayout` as one commit. Omitted parts keep their value. | [Column visibility](/docs/columns/column-visibility) |
| `setColumnOrder` | Moves a column, or a column group, before or after another column. | [Column order and pinning](/docs/columns/column-order-pinning) |
| `setColumnPin` | Pins a column with `"left"` or `"right"`, or unpins it with `null`. | [Column order and pinning](/docs/columns/column-order-pinning) |
| `setColumnWidth` | Writes a column width while a resize drag moves. Fires `onColumnResizing`. | [Column sizing](/docs/columns/column-sizing) |
| `setFilters` | Replaces the filter tree. | [Filtering](/docs/sort-filter-search/filtering) |
| `setPage` | Shows a page of the view. Pages start at 1. Calls `onPageChange`. | [Client pagination](/docs/rows-pages-menus/client-pagination) |
| `setPageSize` | Shows `pageSize` rows per page and keeps the first row of the page on screen. `null` shows every row. | [Client pagination](/docs/rows-pages-menus/client-pagination) |
| `setRowSelected` | Checks or unchecks one row by view index. It sets the state and never toggles. | [Checked rows](/docs/selection-shortcuts/checked-rows) |
| `setSearch` | Sets the quick-search text. With `options`, it also sets the search options. | [Quick search](/docs/sort-filter-search/quick-search) |
| `setSelection` | Applies a whole `SelectionState` in `CellRef` terms. `null` clears the selection. | [Selection and cell events](/docs/events-state/selection-cell-events) |
| `setSorts` | Replaces the active sorts. | [Sorting](/docs/sort-filter-search/sorting) |
| `startEditing` | Opens an editor at a `CellRef`, with optional first text. | [Edit and validation events](/docs/events-state/edit-validation-events) |
| `startEditingAt` | Takes a `ViewCoord` in place of the `CellRef` of `startEditing`. | [Edit and validation events](/docs/events-state/edit-validation-events) |
| `toggleSort` | Steps the sort of a column to the next direction or to no sort, as a header click does. `additive` keeps the other sorts. | [Sorting](/docs/sort-filter-search/sorting) |
| `updateCells` | Writes cell patches by row id in one write, without a view rebuild. Default `source` is `"stream"`. | [Stream updates](/docs/rows-live-data/stream-updates) |
| `updateRows` | Writes whole-row patches by row id. Each `RowPatch` expands to one cell patch per column, as in `updateCells`. | [Stream updates](/docs/rows-live-data/stream-updates) |
