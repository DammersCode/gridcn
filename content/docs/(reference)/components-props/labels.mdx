`DataGridLabels` holds the user-facing strings of the core and most add-ons, grouped by the surface that owns it. `DEFAULT_LABELS` holds the English defaults. The `labels` prop of `DataGrid` and `DataGridProvider` takes a `DeepPartialLabels` object that overrides some of them. The [Labels and i18n guide](/docs/theme-style-language/labels-i18n) shows how to wire a translation library and flip the layout to right to left.

| Group | Surface |
| --- | --- |
| `toolbar` | Quick search, filter menu, header filter, columns menu |
| `sort` | Sort list |
| `filterOperators` | Operator names in the filter menu |
| `contextMenu` | Cell and header context menu, header dropdown |
| `keybindings` | Keybindings dialog |
| `markers` | Row marker column |
| `grid` | Core grid messages: messages for empty, busy, and failed states, the date editor, and screen reader announcements |
| `io` | Export menu, import dialog, print button |
| `pagination` | Pager |
| `statusBar` | Status bar |
| `findReplace` | Find and replace panel |

`DataGridLabels` does not hold two add-on label sets. `DataGridViews` takes its own `labels` ([DataGridViewsLabels](/docs/add-options/sort-filter-search/saved-views-options#labels)). A lookup column takes `options.labels` ([lookup cell](/docs/editing-cells/lookup-cell)).

A label is a string or a function. A function label receives the values that its text needs, such as a count or a page number, and returns the string. The type of each field names its arguments:

```tsx
import {
  DataGrid,
  type DeepPartialLabels,
} from "@/components/data-grid/data-grid";

const labels: DeepPartialLabels = {
  grid: { emptyState: "Keine Zeilen" },
  toolbar: { searchMatches: (current, total) => `${current} von ${total}` },
};

export function EmptyGrid() {
  return (
    <DataGrid className="h-80" defaultData={[]} columns={[]} labels={labels} />
  );
}
```

The empty grid shows "Keine Zeilen". With the toolbar add-on, its search shows "3 von 17" for the third of 17 matches. Every other string stays English.

## Override rules [#override-rules]

- Plain objects merge key by key, at every depth.
- A string, a function, or an array that you set replaces the default as a whole.
- The grid compares `labels` by content, so a literal object of strings needs no `useMemo`. A label that is a function counts as changed when its identity changes.
- `useDataGridLabels()` returns the merged result under the provider.

<Callout type="warn">
  Leave out every key that you do not translate. A key that you set to `undefined` replaces the default with `undefined`. A string label then disappears from the UI, and calling a function label throws an error.
</Callout>
