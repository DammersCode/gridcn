A gridcn item shows as `@gridcn/<item>`, which `registry.json` stores as `DammersCode/gridcn/<item>`. Any other name is a shadcn component. Install a row with `npx shadcn add @gridcn/<item>`. A cell type add-on such as `data-grid-lookup` takes its options on the column, so its guide page lists them, as for the built-in cell types.
