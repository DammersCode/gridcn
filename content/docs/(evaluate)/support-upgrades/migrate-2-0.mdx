Follow these steps to move a grid from gridcn 1.3 to 2.0. [2.0 breaking changes](/docs/support-upgrades/breaking-changes-2-0) lists each change with its 1.3 form, its 2.0 form, and the change to make.

Upgrade to 1.3.0 and commit your work first. For an older version, apply the **Breaking:** entries up to 1.3.0, as [Upgrade gridcn](/docs/support-upgrades/upgrade-gridcn) shows.

## Steps [#steps]

1. Reinstall the core and each add-on that you use, as [Upgrade gridcn](/docs/support-upgrades/upgrade-gridcn#updating-installed-code) shows. Leave out `data-grid-lazy`, because 2.0 has no such item. If you used it, install `data-grid-server` instead.
2. If you used `data-grid-lazy`, move each grid to `useDataGridServerRows`, as [Server rows](#server-rows) shows. Then delete the `components/data-grid-lazy/` folder. A reinstall does not remove it.
3. Run `npx tsc --noEmit`. Each error names a removed or renamed identifier. Find the identifier on [2.0 breaking changes](/docs/support-upgrades/breaking-changes-2-0) and apply its row.
4. Search your CSS and selectors for `data-pinned="left"`, `data-grid-pin-shadow`, `data-scrolled-left`, and `--grid-pin-shadow-left-x`, and their `right` forms. Rename them as the [pin rows](/docs/support-upgrades/breaking-changes-2-0#pin-shadow) show. The type check does not see these names.
5. Check the behavior changes, which compile without an error. The type check does not report them:
   - Sorting and filtering: the [sort language](/docs/support-upgrades/breaking-changes-2-0#sort-locale), the [text order](/docs/support-upgrades/breaking-changes-2-0#text-collator), the [callback timing](/docs/support-upgrades/breaking-changes-2-0#callback-timing), the [empty filtered grid](/docs/support-upgrades/breaking-changes-2-0#no-results), and the [set operators](/docs/support-upgrades/breaking-changes-2-0#set-filter-match).
   - Specs: the [unknown column spec](/docs/support-upgrades/breaking-changes-2-0#unknown-column-spec) and the [equal spec](/docs/support-upgrades/breaking-changes-2-0#equal-spec-no-callback).
   - Selection: the [checkbox state](/docs/support-upgrades/breaking-changes-2-0#checked-rows-only), [row actions over unloaded rows](/docs/support-upgrades/breaking-changes-2-0#row-ops-unloaded), and the [row move under a server sort](/docs/support-upgrades/breaking-changes-2-0#move-server-sort).
   - Editing: [Delete and Cut](/docs/support-upgrades/breaking-changes-2-0#delete-validates), [number text](/docs/support-upgrades/breaking-changes-2-0#number-rejects), [select text](/docs/support-upgrades/breaking-changes-2-0#select-rejects), [bulk writes on "warn" columns](/docs/support-upgrades/breaking-changes-2-0#warn-bulk), and [validate rules](/docs/support-upgrades/breaking-changes-2-0#validate-compose).
   - Clipboard and undo: the [paste and cut results](/docs/support-upgrades/breaking-changes-2-0#paste-refused), the [cut refusal](/docs/support-upgrades/breaking-changes-2-0#cut-refused), the [cut source](/docs/support-upgrades/breaking-changes-2-0#cut-source), [clipboard formulas](/docs/support-upgrades/breaking-changes-2-0#clipboard-formulas), and [undo on a read-only grid](/docs/support-upgrades/breaking-changes-2-0#can-undo-readonly).
   - Columns: the [def `pin` and `hidden`](/docs/support-upgrades/breaking-changes-2-0#pin-hidden-seed), the [cell `z-index`](/docs/support-upgrades/breaking-changes-2-0#cell-z-index), the [column `locale`](/docs/support-upgrades/breaking-changes-2-0#locale-implies-format), and [`setColumnWidth`](/docs/support-upgrades/breaking-changes-2-0#set-column-width).
   - Keys: the [default chords](/docs/support-upgrades/breaking-changes-2-0#default-chords) and the [global shortcut flags](/docs/support-upgrades/breaking-changes-2-0#global-shortcuts), and the [bare-key bindings](/docs/support-upgrades/breaking-changes-2-0#global-shortcuts-modifier).
   - Server data: [stream writes](/docs/support-upgrades/breaking-changes-2-0#stream-readonly), the [stream batch size](/docs/support-upgrades/breaking-changes-2-0#stream-limit), the [request delay](/docs/support-upgrades/breaking-changes-2-0#load-delay), the [loaded row cap](/docs/support-upgrades/breaking-changes-2-0#max-loaded-rows), the [URL parts](/docs/support-upgrades/breaking-changes-2-0#url-state-spec), and the [URL page size](/docs/support-upgrades/breaking-changes-2-0#url-page-size).
   - Import and export: [import on a read-only grid](/docs/support-upgrades/breaking-changes-2-0#import-readonly), the [delimiter detection](/docs/support-upgrades/breaking-changes-2-0#csv-control-chars), the [XLSX part cap](/docs/support-upgrades/breaking-changes-2-0#max-decompressed), the [XLSX cell types](/docs/support-upgrades/breaking-changes-2-0#xlsx-typed), and the [dropzone caption](/docs/support-upgrades/breaking-changes-2-0#dropzone-caption). The `labels.io.noFileChosen` key no longer exists.
   - Add-ons: [find and replace](/docs/support-upgrades/breaking-changes-2-0#find-replace-open), the [`undefined` label](/docs/support-upgrades/breaking-changes-2-0#label-undefined), and the [right-click on a blank area](/docs/support-upgrades/breaking-changes-2-0#right-click-blank).
6. Run your tests.

The type check and the tests pass. Each grid sorts, checks rows, and writes data as your code expects.

## Server rows [#server-rows]

`useDataGridServerRows({ mode: "scroll" })` from `data-grid-server` replaces `useDataGridLazyRows`. `DataGridLazyGuard` has no replacement. If a client sort or filter changes over unloaded rows, the core warns in development.

| 1.3 | 2.0 |
| --- | --- |
| `fetchRows(start, end, signal)` resolves the rows | `fetchRows({ start, end, signal })` resolves `{ rows, totalRowCount?, hasMore?, nextCursor? }` |
| `total` | `totalRowCount` in the answer |
| `batchSize` | `blockSize` |
| `reset()`, `isLoading` | `refresh()`, `loading` |
| `Range` from `data-grid-lazy` | `RowRange` from `data-grid` |
| `maxFetchRows` | none (one block for each request) |
| `onError(error, range)` | `onError(error)` |

Remove your `onRenderedRowsChange` and `onDataChange` wiring, and spread `server.gridProps`:

```tsx
"use client";

import { DataGrid, defineColumns } from "@/components/data-grid/data-grid";
import {
  useDataGridServerRows,
} from "@/components/data-grid-server/data-grid-server";

type Order = { id: string; customer: string };

const columns = defineColumns<Order>()([
  { id: "customer", header: "Customer", accessorKey: "customer" },
]);

export function OrdersGrid() {
  const server = useDataGridServerRows<Order>({
    mode: "scroll",
    blockSize: 100,
    fetchRows: async ({ start, end, signal }) => {
      const query = `offset=${start}&limit=${end - start}`;
      const response = await fetch(`/api/orders?${query}`, { signal });
      const answer = await response.json();
      return { rows: answer.rows, totalRowCount: answer.total };
    },
  });

  return <DataGrid {...server.gridProps} columns={columns} className="h-96" />;
}
```

Scroll mode starts a block request after `loadDelayMs` milliseconds (default 100). Pass `loadDelayMs: 0` for the 1.3 timing. It keeps at most `maxLoadedRows` rows (default 10,000). `Infinity` keeps every row.
