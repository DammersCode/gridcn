Each row is one **Breaking:** entry of the [changelog](https://github.com/DammersCode/gridcn/blob/main/CHANGELOG.md) under `## 2.1.0`. [2.0 breaking changes](/docs/support-upgrades/breaking-changes-2-0) lists the changes from 1.3 to 2.0.

## Server data and query layer [#server-query]

| Change | 2.0 | 2.1 | What to change |
|---|---|---|---|
| <span id="server-group-by-gesture" />Group gesture with server groups and a controlled `groupBy` | Shows the new group columns at once, with the rows ungrouped until the answer lands | Emits `onGroupByChange` and keeps the shown group columns until `groupBy` brings the new layout | Pass the value back as `groupBy`. |
| <span id="query-sub-ms-instants" />Instant with a digit after the millisecond in the query layer | Cut to the millisecond | A filter answers `unsupported-value`. An import or write cell is a `too-many-decimals` refusal, and `rowScope` throws. | Cut the value to the millisecond before the import. |
