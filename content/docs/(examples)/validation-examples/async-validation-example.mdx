## Make a schema async [#make-a-schema-async]

Any Standard Schema whose `validate` returns a promise is async. The function form of `validate` stays synchronous. This column rejects a SKU that the server already holds:

```tsx
import { z } from "zod";
import { DataGrid, defineColumns } from "@/components/data-grid/data-grid";

async function isSkuFree(sku: string) {
  const response = await fetch(`/api/sku/${encodeURIComponent(sku)}`);
  return response.ok;
}

type Item = { id: string; sku: string };

const columns = defineColumns<Item>()([
  {
    id: "sku",
    header: "SKU",
    accessorKey: "sku",
    validate: z.string().refine(isSkuFree, "Already in use"),
  },
]);

export function Items({ items }: { items: Item[] }) {
  return (
    <DataGrid defaultData={items} columns={columns} getRowId={(i) => i.id} />
  );
}
```

## A single edit [#single-cell-edit]

- The editor stays open while the promise is pending. The built-in editors set their input to `readOnly`, never `disabled`, so <kbd>Escape</kbd> still cancels.
- If the schema resolves with issues, the message shows like a sync rejection and editing continues.
- If the schema resolves with a value, the cell commits that value and then makes the move that <kbd>Enter</kbd> asked for.
- <kbd>Escape</kbd>, a newer commit, or an unmounted cell drops the pending result. A stale verdict never lands on a cell the user has left.

## Paste, fill, and `updateCells` [#bulk-paths]

Each of these paths holds the batch while the schema resolves, and so does import:

- The grid runs at most 32 validations at the same time. A paste of 10,000 cells makes 32 calls at a time.
- Nothing changes until every verdict is in. The accepted cells then commit together as one `onDataChange` batch.
- A rejected cell drops, and the other cells still commit. `onValidationError` reports the rejected cells. Its sources are paste, fill, Delete or Cut, find and replace, `updateCells`, and the toggle of an `activate` cell.
- A held batch drops when a sort or filter changes, or when a target row leaves the data.
- The import dialog keeps its Import button disabled while it validates.

While the schema runs, `useDataGridGatePending()` holds `"validate"` and the grid root carries `data-gate-pending="validate"`. A newer paste replaces the held paste. At 200 ms per cell, 10,000 cells take about 60 seconds at 32 calls at a time. To check a large paste against a remote service, validate the whole block once in the `processPaste` override of [Change copy and paste](/docs/clipboard-undo/change-copy-paste).

To skip validation for values that your server already checked, call `actions.updateCells(patches, { skipValidation: true })`.
