Validation in four forms, plus async gates: synchronous rules as a plain function or a Standard Schema library
column (Zod, Joi, Valibot), async checks with a visible pending state, server-side rejections
painted after commit, and cross-field rules via `validateRow`. Async gates cover a server check on paste, edit start,
and row insert. Each page embeds the live
registry example. The [editing guide](/docs/editing-cells/validation#validation) has the full
reference.
