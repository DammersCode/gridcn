One grid shows 5,000 car sales grouped by region, on an in-browser PostgreSQL. The [query layer](/docs/data-modes/query-layer) answers each request with one statement. The panel under the grid shows the last statement and its bound parameters.

## What the demo shows [#whats-in-the-demo]

- `defaultSpec: { groupBy: ["region"] }` makes the first request ask for the groups of the top level.
- Opening a group sends a request with `groupPath` and `childKind: "rows"`. The grid loads the rows in blocks of 50.
- `aggregate: "sum"` on Price adds the revenue to each group row. The database computes it.
- The buttons call `setGroupBy`. A new `groupBy` returns the grid to the first list.
- `fetchRows` passes the request to `demo.query.fetchRows`. The route needs no group code.

## Wire the grid

Pass the whole request to the query layer. The request carries `groupPath` and `childKind`:

```tsx
"use client";

import { DataGrid, defineColumns } from "@/components/data-grid/data-grid";
import { useDataGridServerRows } from "@/components/data-grid-server/data-grid-server";

type CarSale = { id: number; region: string; price: number };

const columns = defineColumns<CarSale>()([
  { id: "region", header: "Region", accessorKey: "region" },
  {
    id: "price",
    header: "Price",
    accessorKey: "price",
    type: "number",
    aggregate: "sum",
  },
]);

export function SalesGrid() {
  const server = useDataGridServerRows<CarSale>({
    mode: "scroll",
    getRowId: (row) => String(row.id),
    defaultSpec: {
      sorts: [],
      filters: [],
      searchText: "",
      groupBy: ["region"],
    },
    fetchRows: async (request) => {
      const response = await fetch("/api/sales", {
        method: "POST",
        headers: { "content-type": "application/json" },
        body: JSON.stringify(request),
        signal: request.signal,
      });
      return response.json();
    },
  });

  return <DataGrid {...server.gridProps} columns={columns} readOnly />;
}
```
