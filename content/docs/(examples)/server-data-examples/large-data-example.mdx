This grid holds all 100,000 rows in memory. It needs no server, no scroll mode, and no pagination. The grid mounts only the rows near the viewport, so the number of rows does not set the number of DOM rows. At 420 px and the default row height of 36 px, the grid mounts about 11 rows plus the overscan rows.

## Load the rows [#how-it-works]

Pass the whole array as `defaultData` and give the grid a bounded height. Sort, filter, and edits then run on the array in memory:

```tsx
import { DataGrid, defineColumns } from "@/components/data-grid/data-grid";

type Person = { id: string; name: string; score: number };

const columns = defineColumns<Person>()([
  { id: "name", header: "Name", accessorKey: "name" },
  { id: "score", header: "Score", accessorKey: "score", type: "number" },
]);

const people: Person[] = Array.from({ length: 100_000 }, (_, i) => ({
  id: `row-${i}`,
  name: `Person ${i}`,
  score: i % 100,
}));

export function BigGrid() {
  return (
    <DataGrid
      defaultData={people}
      columns={columns}
      getRowId={(row) => row.id}
      className="h-96"
    />
  );
}
```

Without a bounded height, the grid mounts at most 200 rows and warns once in development.

<Callout type="info" title="When the rows do not fit in the browser">
  If the result is too large to load, fetch it in blocks with [scroll mode](/docs/scroll-mode/load-rows-while-scrolling) or by page with [server pagination](/docs/server-pagination/load-rows-page).
</Callout>
