This recipe needs a server and is not a registry item. A server grid sends its spec (`sorts`, `filters`, `searchText`) and a row range (`start`, `end`) to your route. The route checks the request and answers `{ rows, totalRowCount }` from a `users` table with a serial `id` and the text columns `name`, `email`, and `role`.

## The route [#the-route]

The route follows the [server rows contract](/docs/contracts/server-rows-contract). It rejects a request that fails the check with status 400. It adds the row id as the last sort, so no two rows tie and a page never repeats a row:

```ts fragment="needs drizzle-orm" title="app/api/grid/route.ts"
import {
  and, asc, count, desc, eq, gt, gte, ilike, inArray, lt, lte, ne,
  notIlike, notInArray, or, sql, type SQL,
} from "drizzle-orm";
import type { PgColumn } from "drizzle-orm/pg-core";
import { db } from "~/db";
import { users } from "~/db/schema";

const { name, email, role } = users;
const COLUMNS: Record<string, PgColumn> = { name, email, role };
const escapeLike = (text: string) => text.replace(/[\\%_]/g, "\\$&");
const infix = (value: string) => `%${escapeLike(value)}%`;

const OPERATORS: Record<string, (c: PgColumn, v: any) => SQL> = {
  contains: (c, v) => ilike(c, infix(v)),
  notContains: (c, v) => notIlike(c, infix(v)),
  startsWith: (c, v) => ilike(c, `${escapeLike(v)}%`),
  endsWith: (c, v) => ilike(c, `%${escapeLike(v)}`),
  equals: eq,
  notEquals: ne,
  gt, gte, lt, lte,
  empty: (c) => eq(c, ""),
  notEmpty: (c) => ne(c, ""),
  isAnyOf: (c, v) => (v.length ? inArray(c, v) : sql`false`),
  isNoneOf: (c, v) => (v.length ? notInArray(c, v) : sql`true`),
};

function isValidLeaf(node: any): boolean {
  if (!Object.hasOwn(COLUMNS, node?.columnId)) return false;
  if (!Object.hasOwn(OPERATORS, node.operator)) return false;
  if (node.operator === "empty" || node.operator === "notEmpty") return true;
  if (node.operator === "isAnyOf" || node.operator === "isNoneOf") {
    return Array.isArray(node.value) && node.value.length <= 1000
      && node.value.every((item: unknown) => typeof item === "string");
  }
  return typeof node.value === "string";
}

function isValidTree(nodes: any, depth = 0, budget = { left: 64 }): boolean {
  return Array.isArray(nodes) && nodes.every((node: any) => {
    if (--budget.left < 0) return false;
    if (!Array.isArray(node?.filters)) return isValidLeaf(node);
    const joins = node.join === "and" || node.join === "or";
    return joins && depth < 2 && isValidTree(node.filters, depth + 1, budget);
  });
}

const isValidSort = (sort: any) =>
  Object.hasOwn(COLUMNS, sort?.columnId) &&
  (sort.direction === "asc" || sort.direction === "desc");

function isValidRequest(body: any): boolean {
  const { spec, start, end } = body ?? {};
  const { sorts, filters, searchText } = spec ?? {};
  return (
    Number.isSafeInteger(start) && start >= 0 && start <= 10_000_000 &&
    Number.isSafeInteger(end) && end > start &&
    typeof searchText === "string" && searchText.length <= 200 &&
    Array.isArray(sorts) && sorts.length <= 8 && sorts.every(isValidSort) &&
    isValidTree(filters)
  );
}

function toWhere(node: any): SQL | undefined {
  if (!Array.isArray(node.filters)) {
    return OPERATORS[node.operator](COLUMNS[node.columnId], node.value);
  }
  const parts: (SQL | undefined)[] = node.filters.map(toWhere);
  if (parts.length === 0) return sql`true`;
  return node.join === "or" ? or(...parts) : and(...parts);
}

export async function POST(request: Request) {
  const body = await request.json().catch(() => null);
  if (!isValidRequest(body)) {
    return new Response("Invalid request", { status: 400 });
  }
  const { spec, start, end } = body;
  const pattern = infix(spec.searchText);
  const where = and(
    spec.searchText
      ? or(ilike(name, pattern), ilike(email, pattern))
      : undefined,
    ...spec.filters.map(toWhere),
  );
  const orderBy = spec.sorts.map((s: any) =>
    (s.direction === "asc" ? asc : desc)(COLUMNS[s.columnId]),
  );

  const [[total], rows] = await Promise.all([
    db.select({ value: count() }).from(users).where(where),
    db.select().from(users).where(where).orderBy(...orderBy, asc(users.id))
      .limit(Math.min(end - start, 500)).offset(start),
  ]);
  return Response.json({ rows, totalRowCount: total.value });
}
```

About the sample:

- The grid sends every value as text. A numeric column needs `Number(value)`.
- The grid compares text without case. The sample uses `ilike` for the pattern operators only. Compare `lower(column)` in the others to match.
- The grid keeps two group levels at most. The sample sets the other caps: 8 sorts, 200 characters of search text, 64 filters and groups, and 1,000 list values. A request over a cap gets status 400.
- Number and date columns also get `isBetween`, a `[min, max]` pair in which either bound can be `""`. The sample refuses it.
- The grid's `empty` also matches a null cell. A nullable column needs an `IS NULL` test.
- The route caps a page at 500 rows. A larger page returns fewer rows than the grid asked for.

<Callout type="warn" title="Check every column id">
Answer 400 if `columnId` is not an own key of `COLUMNS`. `Object.hasOwn` refuses inherited names such as `constructor`. Cap the body size at the framework or proxy, because the tree limits do not bound a large JSON text.
</Callout>

## The client [#the-client]

The grid posts the spec and the range to the route. `fetchRows` returns the JSON as the answer:

```tsx
import { DataGrid, defineColumns } from "@/components/data-grid/data-grid";
import {
  useDataGridServerRows,
} from "@/components/data-grid-server/data-grid-server";

type User = { id: number; name: string };

const columns = defineColumns<User>()([
  { id: "name", header: "Name", accessorKey: "name" },
]);

export function UsersGrid() {
  const server = useDataGridServerRows<User>({
    getRowId: (row) => String(row.id),
    fetchRows: async ({ spec, start, end, signal }) => {
      const body = JSON.stringify({ spec, start, end });
      const init = { method: "POST", body, signal };
      const response = await fetch("/api/grid", init);
      if (!response.ok) throw new Error("Request failed");
      return response.json();
    },
  });
  return <DataGrid {...server.gridProps} columns={columns} />;
}
```

Save edits from `onSave`. See [Handle refused saves](/docs/save-server/handle-refused-saves).

## Shareable state [#shareable-state]

To restore the sort, the filters, the search text, the page, and the page size from the URL, spread `useDataGridUrlPagination()` into the hook options. Mount `DataGridUrlState` in the provider and spread `server.providerProps` and `server.rootProps`. The first request carries the restored spec, so the route stays as it is:

```tsx fragment="inside a component under NuqsAdapter"
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
} from "@/components/data-grid/data-grid";
import {
  DataGridUrlState,
  useDataGridUrlPagination,
} from "@/components/data-grid-url-state/data-grid-url-state";

const url = useDataGridUrlPagination();
const server = useDataGridServerRows<User>({
  getRowId: (row) => String(row.id),
  fetchRows, // the function of the client above
  ...url,
});

return (
  <DataGridProvider columns={columns} {...server.providerProps}>
    <DataGridUrlState />
    <DataGridRoot {...server.rootProps} className="h-96">
      <DataGridHeader />
      <DataGridBody />
    </DataGridRoot>
  </DataGridProvider>
);
```

[URL state](/docs/sort-filter-search/url-state) lists the keys and the adapter setup.
