Two surfaces run the same row operations. A toolbar acts on the rows that the row selection holds. If that selection is empty, it acts on the row of the active cell. In the context menu, Insert works at the clicked row. Duplicate and Delete act on the rows that the selection covers. If the selection is empty, they act on the clicked row. A side panel prints the last change.

## What the demo shows [#whats-in-the-demo]

- The toolbar buttons call `insertRows(anchor, 1, "above")`, `insertRows(anchor, 1, "below")`, `duplicateRows(rows)`, and `deleteRows(rows)`.
- A right-click on a row opens the context menu with Insert, Duplicate, and Delete items.
- The `createRow` and `duplicateRow` props enable Insert and Duplicate. Without them, the menu hides those items.
- The Read-only switch sets `readOnly`. The toolbar buttons and the menu items that change data turn off.
- The side panel shows the `source` and one line per operation.

## Wire the operations

The grid in this sample has a Delete button and the context menu. The button targets the selected rows, or the active row:

```tsx
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  defineColumns,
  useDataGridActions,
  useDataGridActiveCell,
  useDataGridSelection,
} from "@/components/data-grid/data-grid";
import {
  DataGridContextMenu,
} from "@/components/data-grid-context-menu/data-grid-context-menu";
import { Button } from "@/components/ui/button";

type Row = { id: string; name: string };

const columns = defineColumns<Row>()([
  { id: "name", header: "Name", accessorKey: "name" },
]);

const rows: Row[] = [{ id: "1", name: "Ada" }];

function DeleteButton() {
  const actions = useDataGridActions();
  const activeCell = useDataGridActiveCell();
  const checked = useDataGridSelection().rows;
  const hasChecked = checked.length > 0;
  // Read the indexes on click: a render-time toArray() copies every checked row.
  const deleteTargets = () =>
    actions.deleteRows(
      hasChecked ? checked.toArray() : activeCell ? [activeCell.row] : [],
    );

  return (
    <Button
      disabled={!hasChecked && !activeCell}
      onClick={deleteTargets}
    >
      Delete
    </Button>
  );
}

function RowOpsGrid() {
  return (
    <DataGridProvider
      defaultData={rows}
      columns={columns}
      getRowId={(row) => row.id}
      createRow={() => ({ id: crypto.randomUUID(), name: "New row" })}
      duplicateRow={(row) => ({ ...row, id: crypto.randomUUID() })}
      onDataChange={(_, change) => console.log(change.source, change.ops)}
    >
      <DeleteButton />
      <DataGridContextMenu>
        <DataGridRoot>
          <DataGridHeader />
          <DataGridBody />
        </DataGridRoot>
      </DataGridContextMenu>
    </DataGridProvider>
  );
}
```

## The change [#the-operation-shape-contract]

Every insert, duplicate, and delete reports one change with `source: "row-operation"`. An insert and a duplicate write `insert` operations. A delete writes `delete` operations. Each operation names its row by `rowId` and carries the `row` and its data `index`.

Because the operations name rows by id, history can undo a row operation after a sort or filter. History records `"row-operation"` changes by default.

## Confirm a delete [#confirm-delete]

<NewBadge />

`onBeforeDeleteRows` runs before each delete that the grid starts. In this demo, it opens a dialog for the Delete rows shortcut and for the menu item:

<ComponentPreview name="data-grid-delete-confirm-demo" />

<InstallCommand item="data-grid-delete-confirm-demo" />

- `rowMarkers="checkbox"` and `keepCheckedRows` make the delete act on the checked rows.
- `onBeforeDeleteRows` returns a promise. Cancel resolves it with `false` and keeps the rows. Delete resolves it with `true`. A dismissed dialog resolves it with `false`.
- The Cancel button gets the focus when the dialog opens.
