One grid uses all four pin zones. Name sits in the start band and Score sits in the end band. An averages row fills the top band and a totals row fills the bottom band. The [pinned rows](/docs/rows-pages-menus/pinned-rows) add-on owns the bands.

## What the demo shows [#whats-in-the-demo]

- `pin: "left"` on Name and `pin: "right"` on Score pin the column bands.
- `useDataGridPinnedRows` takes `topRows` and `bottomRows`. The top band holds the averages row. The bottom band holds the totals row.
- `DataGridAggregateReporter` computes both rows from the rows that pass the filter (its `scope` defaults to `"view"`).
- The grid has nine columns and 200 rows. Scroll it in both directions.

## Wire the zones

Render one reporter per computed row inside the provider. Each reporter sends its row to a state in the parent component. The parent passes both states to the hook. Memoize the band arrays:

```tsx
import { useCallback, useMemo, useState } from "react";
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  defineColumns,
} from "@/components/data-grid/data-grid";
import {
  DataGridAggregateReporter,
  useDataGridPinnedRows,
  type AggregateSpecs,
} from "@/components/data-grid-pinned-rows/data-grid-pinned-rows";

type Row = { id: string; name: string; age: number; score: number };

const columns = defineColumns<Row>()([
  { id: "name", header: "Name", accessorKey: "name", pin: "left" },
  { id: "age", header: "Age", accessorKey: "age", type: "number" },
  {
    id: "score",
    header: "Score",
    accessorKey: "score",
    type: "number",
    pin: "right",
  },
]);

const rows: Row[] = [{ id: "1", name: "Ada", age: 36, score: 90 }];

const AVERAGE_SPECS: AggregateSpecs = { age: "avg", score: "avg" };
const TOTAL_SPECS: AggregateSpecs = { age: "sum", score: "sum" };

function PinnedGrid() {
  const [average, setAverage] = useState<Record<string, unknown>>({
    id: "average",
    name: "Average",
  });
  const [total, setTotal] = useState<Record<string, unknown>>({
    id: "total",
    name: "Total",
  });
  const onAverage = useCallback((row: Record<string, unknown>) => {
    setAverage((prev) => ({ ...prev, ...row }));
  }, []);
  const onTotal = useCallback((row: Record<string, unknown>) => {
    setTotal((prev) => ({ ...prev, ...row }));
  }, []);

  const topRows = useMemo(() => [average], [average]);
  const bottomRows = useMemo(() => [total], [total]);
  const { plugin } = useDataGridPinnedRows({ topRows, bottomRows });
  const plugins = useMemo(() => [plugin], [plugin]);

  return (
    <DataGridProvider defaultData={rows} columns={columns} plugins={plugins}>
      <DataGridAggregateReporter specs={AVERAGE_SPECS} onChange={onAverage} />
      <DataGridAggregateReporter specs={TOTAL_SPECS} onChange={onTotal} />
      <DataGridRoot>
        <DataGridHeader />
        <DataGridBody />
      </DataGridRoot>
    </DataGridProvider>
  );
}
```

## Behavior [#behavior-reference]

- The pinned columns stay at their edges during a horizontal scroll.
- The pinned bands stay under the header and at the bottom edge during a vertical scroll. The data rows scroll beneath them.
- A cell in a pinned column and a pinned band stays fixed on both axes.
- A band casts a soft shadow after data rows scroll beneath it. See [scroll shadows](/docs/theme-style-language/density-small-screens#scroll-shadows).
