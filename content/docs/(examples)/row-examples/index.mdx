One example per row feature: row operations (insert, duplicate, delete from the toolbar or the
context menu, with the `onDataChange` operation payload made visible), the row-marker column with its
modes and custom renderers, the action-buttons column pattern, and streaming data with deferred
or immediate re-sorting. Each page embeds the live registry example. The
[row operations guide](/docs/rows-pages-menus) has the full reference.
