A row actions column is a pinned-right, read-only column. Its `renderCell` draws buttons, and each button calls a grid action. The grid needs no extra feature for this pattern.

## The two patterns [#the-two-patterns]

- Inline buttons suit one or two actions that every row uses. They take horizontal space in each row.
- A "more" dropdown suits three or more actions, or rare ones. It adds one click to each action.

The demo shows both. Two icon buttons run Edit and Delete, and a dropdown holds Edit, Duplicate, and Delete.

## How it is wired [#how-its-wired]

`renderCell` receives `viewRowIndex`, the position of the row in the view. The row actions take the same index. Call `useDataGridActions` in a component that `renderCell` renders:

```tsx
import {
  DataGrid,
  defineColumns,
  useDataGridActions,
} from "@/components/data-grid/data-grid";
import { Button } from "@/components/ui/button";

type Row = { id: string; name: string };

function RowActions({ viewRowIndex }: { viewRowIndex: number }) {
  const actions = useDataGridActions();

  return (
    <div className="flex justify-end gap-1">
      <Button
        size="sm"
        variant="ghost"
        onClick={() => actions.startEditingAt({ row: viewRowIndex, col: 0 })}
      >
        Edit
      </Button>
      <Button
        size="sm"
        variant="ghost"
        onClick={() => actions.duplicateRows([viewRowIndex])}
      >
        Duplicate
      </Button>
      <Button
        size="sm"
        variant="ghost"
        onClick={() => actions.deleteRows([viewRowIndex])}
      >
        Delete
      </Button>
    </div>
  );
}

const columns = defineColumns<Row>()([
  { id: "name", header: "Name", accessorKey: "name" },
  {
    id: "actions",
    header: <span className="sr-only">Actions</span>,
    accessorFn: () => "",
    pin: "right",
    readOnly: true,
    width: 220,
    renderCell: ({ viewRowIndex }) => (
      <RowActions viewRowIndex={viewRowIndex} />
    ),
  },
]);

const rows: Row[] = [{ id: "1", name: "Ada" }];

function ActionsGrid() {
  return (
    <DataGrid
      defaultData={rows}
      columns={columns}
      getRowId={(row) => row.id}
      duplicateRow={(row) => ({ ...row, id: crypto.randomUUID() })}
    />
  );
}
```

`startEditingAt` starts an edit in the cell at a view row and a column position. Here, column 0 is Name. Without a `duplicateRow` prop, `duplicateRows` does nothing and warns in development.

To address a row by its identity, use the `rowId` that `renderCell` receives. `startEditing` takes a `{ rowId, columnId }` cell ref, and `deleteRowsById` takes row ids.
