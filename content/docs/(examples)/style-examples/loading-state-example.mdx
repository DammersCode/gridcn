The `loading` prop and the number of rows in view decide what the grid shows. In the demo, the Loading switch sets `loading`, and the Rows present switch adds or removes the rows. Together they reach every state in the table.

<ComponentPreview name="data-grid-loading-demo" />

<InstallCommand item="data-grid-loading-demo" />

| Rows in view | `loading` | The grid shows |
|---|---|---|
| none | `true` | Skeleton rows that fill the viewport. |
| some | `true` | A slim indeterminate bar under the header. The rows stay on screen. |
| none | `false` | The empty state, with the text `labels.grid.emptyState`. |

<Callout type="info" title="Where the data comes from">
`loading` changes what the grid shows and fetches nothing. Pass the flag from the code that owns your request. The server rows hook returns `loading` in `gridProps`.
</Callout>

## Customizing the look [#customizing-the-look]

While `loading` is true, `loadingState` replaces the skeleton and the bar. It takes a node, or a function that receives `{ reason }`. If no rows are in view, the reason is `"no-data"`. If rows are in view, it is `"rows-present"`. The grid renders the result under the header at full width, and the result owns its accessibility.

`emptyState` takes the same two forms. If `data` is empty and no server filter or search is active, its reason is `"no-data"`. In every other case the reason is `"filtered"`:

The sample passes `data` without `onDataChange`, so it sets `readOnly`:

```tsx
import { DataGrid, defineColumns } from "@/components/data-grid/data-grid";

type Order = { id: string; customer: string };

const columns = defineColumns<Order>()([
  { id: "customer", header: "Customer", accessorKey: "customer" },
]);

export function Orders({ rows, loading }: { rows: Order[]; loading: boolean }) {
  return (
    <DataGrid
      className="h-80"
      data={rows}
      columns={columns}
      readOnly
      loading={loading}
      loadingState={({ reason }) => (
        <p className="p-4 text-sm">
          {reason === "no-data" ? "Fetching orders…" : "Refreshing…"}
        </p>
      )}
      emptyState={({ reason }) =>
        reason === "filtered" ? "No order matches" : "No orders yet"
      }
    />
  );
}
```
