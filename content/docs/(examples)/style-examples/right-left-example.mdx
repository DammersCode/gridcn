The demo has three locales: English, Deutsch, and Arabic. Each locale sets the `labels` of the grid, the column headers, a hint text, and a text direction. Pick a language. The strings change, and the Arabic locale flips the grid to right-to-left.

## The labels prop [#the-labels-prop]

The grid keeps every user-facing string in one `DataGridLabels` object with English defaults. The `labels` prop of `DataGridProvider` and `DataGrid` deep-merges over it. Only the keys you set change. A label that holds a value, such as `searchMatches`, is a function that receives the values.

Column headers are not labels. They belong to the column definitions, so build the columns from the locale and memoize them.

## RTL [#rtl]

`direction` is `"ltr"` or `"rtl"`. Take it from the same locale record as the labels. The demo also sets `dir` on the element around the grid, so the page around the grid mirrors with it:

```tsx
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  defineColumns,
  type DeepPartialLabels,
  type GridDirection,
} from "@/components/data-grid/data-grid";

type Locale = "en" | "de" | "ar";
type Row = { id: string; name: string };

const TRANSLATIONS: Record<
  Locale,
  { dir: GridDirection; labels: DeepPartialLabels }
> = {
  en: { dir: "ltr", labels: {} },
  de: { dir: "ltr", labels: { grid: { emptyState: "Keine Zeilen" } } },
  ar: { dir: "rtl", labels: { grid: { emptyState: "لا صفوف" } } },
};

const columns = defineColumns<Row>()([
  { id: "name", header: "Name", accessorKey: "name" },
]);

export function LocaleGrid({ locale }: { locale: Locale }) {
  const { dir, labels } = TRANSLATIONS[locale];
  return (
    <div dir={dir}>
      <DataGridProvider defaultData={[]} columns={columns} labels={labels}>
        <DataGridRoot className="h-48" direction={dir}>
          <DataGridHeader />
          <DataGridBody />
        </DataGridRoot>
      </DataGridProvider>
    </div>
  );
}
```

With no rows, the grid shows the empty-state text of the locale. In `rtl`, the grid mirrors the column order, the pinned bands, the pointer math, and the placement of popups. The arrow keys move visually, so <kbd>ArrowRight</kbd> goes to the column on the right of the screen. If you omit `direction`, the grid reads the direction it inherits from the page once, at mount. A locale switch changes the direction at run time, so pass `direction`.
