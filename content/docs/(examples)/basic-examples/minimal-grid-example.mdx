The smallest working grid needs the `data-grid` item, a column list, and `defaultData`. The grid seeds its rows once from `defaultData`, then owns them and applies every edit itself.

## What the demo shows [#whats-in-the-demo]

- `DataGrid` composes the provider, the scroll root, the header, and the body.
- `defineColumns` types three columns: `text`, `number`, and `checkbox`.
- `defaultData` seeds the rows. The grid ignores later changes to the prop.
- `className` sizes the grid. The demo sets `w-full h-[240px]`.

The grid reads the row id from the `id` field of each row. If your rows have no `id` field, pass `getRowId`. If the app must own the rows, pass `data` and `onDataChange`.

A minimal version of the demo, with its imports:

```tsx
import { DataGrid, defineColumns } from "@/components/data-grid/data-grid";

type Person = { id: string; name: string; age: number; active: boolean };

const columns = defineColumns<Person>()([
  { id: "name", header: "Name", accessorKey: "name", type: "text" },
  { id: "age", header: "Age", accessorKey: "age", type: "number" },
  { id: "active", header: "Active", accessorKey: "active", type: "checkbox" },
]);

const rows: Person[] = [
  { id: "1", name: "Ada Lovelace", age: 28, active: true },
  { id: "2", name: "Grace Hopper", age: 34, active: true },
];

export function PeopleGrid() {
  return <DataGrid defaultData={rows} columns={columns} className="h-60" />;
}
```
