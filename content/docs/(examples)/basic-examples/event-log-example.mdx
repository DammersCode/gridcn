The grid reports each user action through a callback prop. In the demo, every callback writes its payload to the Event inspector panel, newest first. The panel keeps the last 20 entries.

## What the demo shows [#whats-in-the-demo]

- A click, a double-click, and a right-click on a cell log `onCellClick`, `onCellDoubleClick`, and `onCellContextMenu`. A move of the active cell logs `onActiveCellChange`.
- An edit logs `onBeforeEditStart`, then `onEditEnd`. A committed value logs `onDataChange` with the change.
- A drag over cells logs `onSelectionChange`. The panel shows the first five rows of `details.getValues()`.
- A header click logs `onSortChange`, because the demo sets `headerClickBehavior="sort"`. The filter menu logs `onFilterChange`.
- A scroll logs `onRenderedRowsChange`. A column resize logs `onColumnResizing` on each drag frame and `onColumnLayoutChange` on release. A pin or a hide from the header menu logs `onColumnLayoutChange`.
- A paste or fill that refuses a cell logs `onValidationError`. A single refused edit logs `onEditEnd` with `result: "rejected"`.
- A fill-handle drag logs one `onDataChange`.
- Quick search logs no entry.
- The Simulate presence highlight button calls `setPresenceHighlights` of `useDataGridPresence`. The panel logs the highlights that it sets.

Each callback appends one entry to a capped list:

```tsx
import { useCallback, useState } from "react";
import { DataGrid, defineColumns } from "@/components/data-grid/data-grid";

type Row = { id: string; name: string };
type Entry = { event: string; payload: unknown };

const columns = defineColumns<Row>()([
  { id: "name", header: "Name", accessorKey: "name" },
]);

const rows: Row[] = [{ id: "1", name: "Ada" }];

export function LoggedGrid() {
  const [log, setLog] = useState<Entry[]>([]);
  const record = useCallback((event: string, payload: unknown) => {
    setLog((prev) => [{ event, payload }, ...prev].slice(0, 20));
  }, []);

  return (
    <>
      <DataGrid
        defaultData={rows}
        columns={columns}
        headerClickBehavior="sort"
        onDataChange={(_next, change) => record("onDataChange", change)}
        onSortChange={(sorts) => record("onSortChange", sorts)}
      />
      <pre>{JSON.stringify(log, null, 2)}</pre>
    </>
  );
}
```
