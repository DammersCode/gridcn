`DataGridPrintButton` opens the browser print dialog with a plain table of the current view. In the demo, the Page size select passes `paperSize` to the button. To check the size, choose "Save as PDF" in the dialog.

<InstallCommand item="data-grid-print-demo" />

The button passes its `options` prop to `printGrid`:

```tsx
import { DataGridPrintButton } from "@/components/data-grid-io/data-grid-io";

export function PrintLetterButton() {
  return (
    <DataGridPrintButton options={{ paperSize: "Letter", title: "Orders" }} />
  );
}
```

Place the button inside `DataGridProvider`, for example in `DataGridToolbar`. `paperSize` is `"A4"` (default), `"A3"`, `"Letter"`, or `"Legal"`. `title` prints as a heading and sets the document title.

## What the demo shows [#whats-in-the-demo]

- The printed table follows the view: the current sort, filters, and visible column order.
- The page is landscape when the grid shows more than 6 columns, and portrait otherwise.
- The table prints at most 10,000 rows by default.
