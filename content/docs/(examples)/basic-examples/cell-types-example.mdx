The grid has one column for each built-in cell type. Extra columns show a read-only column, number options, and a `renderCell` display override. Press <kbd>Enter</kbd> or <kbd>F2</kbd> on a cell to open its editor.

## What the demo shows [#whats-in-the-demo]

- `text` is the type of a column that sets no `type`.
- `readOnly: true` on a column refuses edits, pastes, and fills for its cells.
- `number` with `options: { min: 18, max: 100 }` clamps a typed or pasted value into that range.
- `number` with `options.format` shows `style: "currency"` text. Copy, export, and the editor keep the raw number.
- `checkbox`, `select` with `choices`, and `date` with `displayFormat` use the other built-in editors.
- `url` renders a link. The link opens on <kbd>Alt</kbd>+<kbd>Enter</kbd>. The demo row with a `javascript:` value renders as plain text.
- `longText` opens a multi-line editor in a popover. <kbd>Shift</kbd>+<kbd>Enter</kbd> inserts a line break.
- `renderCell` on a `number` column draws a progress bar. The `number` type still handles editing, paste, and sort.
