Press <kbd>Enter</kbd> or <kbd>F2</kbd> on a cell to edit it. Drag over cells to select a range. Press <kbd>Ctrl</kbd>+<kbd>C</kbd> or <kbd>Ctrl</kbd>+<kbd>V</kbd> to copy and paste. Drag the fill handle to copy or continue a series.

## What the demo shows [#whats-in-the-demo]

- Seven columns use `text`, `number`, `checkbox`, `select`, and `date`. The `number` columns set `min` and `max`, the `select` column sets `choices`, and the `date` column sets `displayFormat`.
- `defaultData` seeds twelve rows from `generateDemoRows(12)`. The demo keeps no state.
- `DataGridProvider`, `DataGridRoot`, `DataGridHeader`, and `DataGridBody` compose the grid in parts.
- `useDataGridFill` returns `{ plugin }`. The demo passes `plugin` in the `plugins` prop of `DataGridProvider`. The plugin renders its own mount inside `DataGridRoot`, so the demo adds no child for it.
- Range selection and the clipboard belong to the core. They need no add-on.

The provider with the fill add-on:

```tsx
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  defineColumns,
} from "@/components/data-grid/data-grid";
import { useDataGridFill } from "@/components/data-grid-fill/data-grid-fill";

type Row = { id: string; name: string; age: number };

const columns = defineColumns<Row>()([
  { id: "name", header: "Name", accessorKey: "name" },
  { id: "age", header: "Age", accessorKey: "age", type: "number" },
]);

const rows: Row[] = [{ id: "1", name: "Ada", age: 36 }];

export function FillGrid() {
  const { plugin } = useDataGridFill();
  return (
    <DataGridProvider defaultData={rows} columns={columns} plugins={[plugin]}>
      <DataGridRoot className="h-60">
        <DataGridHeader />
        <DataGridBody />
      </DataGridRoot>
    </DataGridProvider>
  );
}
```
