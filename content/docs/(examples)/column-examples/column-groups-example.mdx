Three groups sit above the columns: Contact, Work, and Standing. Work holds a nested History group, so the header has three rows. The demo pins Name to the start edge, so the Contact header splits at the pin edge.

## What the demo shows [#whats-in-the-demo]

- `columnGroups` is a list of `{ id, header, children }` objects. `children` lists column ids and nested groups.
- In the default `select` mode, a press on a group header selects the columns under that header cell. The Contact header has two cells, so a press on its pinned cell selects Name only.
- A drag on a group header moves the group as one block inside its parent. A drag on a column moves it inside its group.
- The Contact header splits in two cells because the demo pins Name and leaves Email unpinned.
- If the user hides every column of a group, the group header disappears.
- `DataGridColumnsMenu` lists the members of each group under the group label.

The demo passes this list to `columnGroups`:

```tsx
import type { ColumnGroupDef } from "@/components/data-grid/data-grid";

export const columnGroups: readonly ColumnGroupDef[] = [
  { id: "contact", header: "Contact", children: ["name", "email"] },
  {
    id: "work",
    header: "Work",
    children: [
      "role",
      { id: "history", header: "History", children: ["joined", "age"] },
    ],
  },
  { id: "standing", header: "Standing", children: ["score", "active"] },
];
```
