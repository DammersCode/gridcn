`defaultColumnLayout` seeds the widths, order, pins, and hidden columns once at mount. `onColumnLayoutChange` reports the layout after each change. The demo saves the layout to `localStorage`. Resize a header, drag a column, or hide one, then reload the page to see the grid restore the layout.

## What the demo shows [#whats-in-the-demo]

- `defaultColumnLayout={layout}` seeds the grid once at mount. The server has no `localStorage`, so the demo reads the saved layout in an effect and mounts the grid after it. The grid ignores later changes to this prop.
- `onColumnLayoutChange={persist}` runs once for each committed change: a resize release, a reorder drop, a pin or unpin, and a hide or show. It does not run for each drag frame.
- `DataGridColumnsMenu` hides and restores columns, which updates `hidden`.
- Reset layout clears the saved layout and mounts the grid again with a new `key`, because the grid reads `defaultColumnLayout` once.
- The text above the grid lists the `order` of the most recent snapshot.

## The snapshot [#the-snapshot-shape]

`onColumnLayoutChange` receives the whole layout after each change. `widths` lists only the columns that the user resized. `order` lists every column id. `pins` maps a column id to `"start"` or `"end"`, and `hidden` lists the hidden column ids. This grid saves the layout and restores it after mount:

```tsx
"use client";

import { useEffect, useState } from "react";
import {
  DataGrid,
  defineColumns,
  type ColumnLayout,
} from "@/components/data-grid/data-grid";

type Person = { id: string; name: string; age: number };

const columns = defineColumns<Person>()([
  { id: "name", header: "Name", accessorKey: "name" },
  { id: "age", header: "Age", accessorKey: "age", type: "number" },
]);

const rows: Person[] = [{ id: "1", name: "Ada", age: 36 }];

const STORAGE_KEY = "people-grid-layout";

function readLayout(): ColumnLayout | undefined {
  try {
    const raw = window.localStorage.getItem(STORAGE_KEY);
    return raw ? (JSON.parse(raw) as ColumnLayout) : undefined;
  } catch {
    return undefined;
  }
}

function saveLayout(layout: ColumnLayout) {
  try {
    window.localStorage.setItem(STORAGE_KEY, JSON.stringify(layout));
  } catch {
    return;
  }
}

export function PeopleGrid() {
  const [layout, setLayout] = useState<ColumnLayout | undefined | null>(null);
  useEffect(() => setLayout(readLayout()), []);
  if (layout === null) return null;

  return (
    <DataGrid
      defaultData={rows}
      columns={columns}
      className="h-60"
      defaultColumnLayout={layout}
      onColumnLayoutChange={saveLayout}
    />
  );
}
```

To reset without a remount, pass `columnLayout` with `onColumnLayoutChange`.
