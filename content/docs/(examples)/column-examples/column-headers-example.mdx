`ColumnDef.header` takes a string or a React node. Click the Name or Score header to sort. A minus icon means no sort. An up icon means ascending. A down icon means descending.

## What the demo shows [#whats-in-the-demo]

- `headerClickBehavior="sort"` makes a header click sort the column up, then down, then clear the sort.
- `header` on Name and Score is a node. A node header renders as it is and owns its display, so the grid adds no sort arrow to it.
- `SortStateIcon` calls `useDataGridSortState()` to read the sort list and picks an icon from the entry of its column.
- `headerText` gives the plain-text label of a column whose `header` is a node. Without it, the label is the column id.
- Email keeps a string header. The grid appends the built-in sort arrow to it.

To keep the built-in arrow in a node header, render `<DataGridSortIndicator columnId="score" />` inside it.
