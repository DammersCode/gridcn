Two paths change the column order: drag a header, or call `actions.setColumnOrder(id, targetId, position)`. The demo offers both. The demo sets `reorderable: false` on Name and pins Score to the end edge.

## What the demo shows [#whats-in-the-demo]

- `enableColumnReorder` lets the user drag a header. The grid shows a drop indicator. The prop defaults to `true`.
- `reorderable: false` on Name keeps that column in place, while `enableColumnReorder` is `true`.
- A column moves only inside its pin zone. A drop across zones does nothing. Score is the only column pinned to the end edge, so it has nowhere to move.
- The picker and the Left and Right buttons call `setColumnOrder(selectedId, neighborId, "before" | "after")`. The buttons come from `useDataGridActions()`. A button is off when the move is not possible. That is the case at the ends of the order, next to a column with `reorderable: false`, and across a pin zone.

This grid keeps Name in place and moves Email one step later with a button:

```tsx
import {
  DataGridBody,
  DataGridHeader,
  DataGridProvider,
  DataGridRoot,
  defineColumns,
  useDataGridActions,
} from "@/components/data-grid/data-grid";
import { Button } from "@/components/ui/button";

type Person = { id: string; name: string; email: string; role: string };

const columns = defineColumns<Person>()([
  { id: "name", header: "Name", accessorKey: "name", reorderable: false },
  { id: "email", header: "Email", accessorKey: "email" },
  { id: "role", header: "Role", accessorKey: "role" },
]);

const rows: Person[] = [
  { id: "1", name: "Ada", email: "ada@example.com", role: "Admin" },
];

function MoveEmailButton() {
  const actions = useDataGridActions();
  return (
    <Button
      variant="outline"
      size="sm"
      disabled={!actions.canSetColumnOrder("email", "role", "after").ok}
      onClick={() => actions.setColumnOrder("email", "role", "after")}
    >
      Move Email after Role
    </Button>
  );
}

export function PeopleGrid() {
  return (
    <DataGridProvider defaultData={rows} columns={columns}>
      <MoveEmailButton />
      <DataGridRoot className="h-60">
        <DataGridHeader />
        <DataGridBody />
      </DataGridRoot>
    </DataGridProvider>
  );
}
```
