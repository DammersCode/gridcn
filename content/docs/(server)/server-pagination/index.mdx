In pages mode, your server returns one page of rows for each request. The grid shows that page and a pager for the footer.

If the whole array lives in the browser, use client pagination instead. See [Client pagination](/docs/rows-pages-menus/client-pagination). To pick between pages and scroll mode, see [Compare data modes](/docs/server-path/compare-data-modes).
