The receiving side is the `data-grid-presence` add-on, which [Show presence](/docs/rows-live-data/show-presence) covers. This page covers the other direction. You send the local selection to a websocket, and the server relays a snapshot of all peers.

## Wire the websocket and send the selection [#wiring-a-real-websocket]

`onSelectionChange` on the grid fires on every committed change: a click, a drag-extend step, a row, column, or all selection, and a clear. Its first argument is the stable `SelectionState`. It holds row ids and column ids and no view positions. The second argument has `getRowIds()`, which lists every selected row in view order.

Send the row ids and the column ids between the two corners of the range:

```tsx
"use client";

import { useEffect, useRef } from "react";
import { DataGrid, defineColumns } from "@/components/data-grid/data-grid";
import {
  useDataGridPresence,
  type PresenceHighlightEntry,
} from "@/components/data-grid-presence/data-grid-presence";

type Row = { id: string; name: string };

const columns = defineColumns<Row>()([
  { id: "name", header: "Name", accessorKey: "name" },
]);

type Props = { rows: Row[]; roomId: string; userId: string; color: string };

export function SharedGrid({ rows, roomId, userId, color }: Props) {
  const { plugin, setPresenceHighlights } = useDataGridPresence();
  const socketRef = useRef<WebSocket | null>(null);
  const timerRef = useRef<ReturnType<typeof setTimeout>>(undefined);

  function send(message: object) {
    clearTimeout(timerRef.current);
    timerRef.current = setTimeout(() => {
      const socket = socketRef.current;
      if (socket?.readyState !== WebSocket.OPEN) return;
      socket.send(JSON.stringify(message));
    }, 100);
  }

  useEffect(() => {
    const socket = new WebSocket(`wss://your-server/rooms/${roomId}`);
    socketRef.current = socket;
    socket.onmessage = (event) => {
      let peers: unknown;
      try {
        peers = JSON.parse(event.data);
      } catch {
        return;
      }
      if (!Array.isArray(peers)) return;
      setPresenceHighlights(
        peers.filter(
          (peer): peer is PresenceHighlightEntry =>
            typeof peer === "object" &&
            peer !== null &&
            peer.id !== userId,
        ),
      );
    };
    return () => {
      clearTimeout(timerRef.current);
      socket.close();
    };
  }, [roomId, userId, setPresenceHighlights]);

  const columnIds: string[] = columns.map((column) => column.id);

  return (
    <DataGrid
      data={rows}
      columns={columns}
      getRowId={(row) => row.id}
      plugins={[plugin]}
      onSelectionChange={(next, details) => {
        if (!next.range) {
          send({ type: "leave", id: userId });
          return;
        }
        const { start, end } = next.range;
        const from = columnIds.indexOf(start.columnId);
        const to = columnIds.indexOf(end.columnId);
        const [lo, hi] = from < to ? [from, to] : [to, from];
        const span = columnIds.slice(lo, hi + 1);
        send({
          type: "selection",
          id: userId,
          color,
          rowIds: details.getRowIds(),
          columnIds: span,
        });
      }}
    />
  );
}
```

The sample takes the column span from the order of `columns`. If users reorder or hide columns, build `columnIds` from the visible column order instead, for example with `useDataGridVisibleColumns()` in a component under the provider.

## Relay a snapshot [#sending-your-selection]

`setPresenceHighlights` replaces the whole list. So your server answers every `selection` or `leave` message with the full list of peers. Each entry is a row-id range entry with the `id`, `color`, `rowIds`, and `columnIds` that the peer sent. The sample above filters out the entry of the local user. This relay keeps the last message of each peer:

```ts fragment="server side; socket is one client of a ws server"
const peers = new Map<string, unknown>();

socket.on("message", (data) => {
  const message = JSON.parse(String(data));
  if (message.type === "leave") peers.delete(message.id);
  else peers.set(message.id, message);
  const snapshot = JSON.stringify([...peers.values()]);
  for (const client of server.clients) client.send(snapshot);
});
```

The receiver resolves the ids against its own view. The receiver drops a row that a local filter hides and a hidden column. A message from a fuller view therefore paints cleanly on a narrower one.

`getRowIds()` lists every selected row, and checked rows count too. A select-all of 100,000 rows sends 100,000 ids. Cap the list on the sender or on the server.

- In scroll mode, `getRowIds()` skips unloaded rows. A peer paints only the loaded rows of the range. `getViewRowIds({ loaded: true })` on the grid ref lists the same loaded rows of the whole view.
- The sample sends the columns of the main range only. A selection of checked rows or whole columns has no `range`, so the sample reports it as a leave.
- `getRowIds()` lists the rows of every range and the checked rows together. For several ranges, build the row ids of each range from its corners and the view order, and send one entry per range.
- The sample waits 100 ms after the last change before it sends, because a drag fires one change for each step.

Treat every incoming message as untrusted input. The add-on drops malformed entries and repairs a bad `label` or `color`: [Presence options](/docs/add-options/server/presence-options) lists each rule. The add-on renders a `label` as text.
