`insertRow`, `insertRows`, `duplicateRows`, `deleteRows`, and `deleteRowsById` can do nothing. They tell you why. A gate such as `onBeforeDeleteRows` can also wait forever. This page covers both. See [Change server rows](/docs/rows-live-data/change-server-rows) for the actions.

## Read the result of an action [#action-results]

Each of the five row actions returns `{ ok: true }` once it ran or an async gate started. Otherwise it returns `{ ok: false, reason }`. The `reason` names the cause:

| `reason` | Meaning |
| --- | --- |
| `"readOnly"` | The grid is read-only. |
| `"unloaded-rows"` | A target row is not loaded. |
| `"gate-pending"` | The promise of `createRow`, `duplicateRow`, or `onBeforeDeleteRows` has not settled. |
| `"no-factory"` | `createRow` or `duplicateRow` is missing. |
| `"gate-declined"` | `onBeforeDeleteRows` returned `false`. |
| `"gate-threw"` | `onBeforeDeleteRows` threw. |
| `"nothing-to-do"` | No target row matched, or `count` was 0. |

A call with `source: "stream"` returns `{ ok: true }` when no id matched, because a server push can repeat a delete.

Two more reasons reach `onRowActionSkipped` from the shortcuts only. No action runs for them:

| `reason` | Meaning |
| --- | --- |
| `"hidden-checked"` | The shortcut found only checked rows that the view does not show. |
| `"all-matching"` | The shortcut found all matching on. |

`onRowActionSkipped({ action, reason })` <NewBadge /> on `DataGridProvider` fires when `insertRows`, `duplicateRows`, or `deleteRows` does nothing. It also fires when the Insert row, Duplicate row, or Delete rows shortcut has a target and does nothing. A shortcut with no active cell and no selection has no target, so it reports nothing. A disabled item of the context menu runs nothing and fires nothing. It shows the reason as a tooltip.

Pass the handler to `DataGridProvider`:

```tsx
import { DataGridProvider, DataGridRoot } from "@/components/data-grid/data-grid";

<DataGridProvider
  defaultData={[]}
  columns={[]}
  onRowActionSkipped={({ action, reason }) => console.log(action, reason)}
>
  <DataGridRoot />
</DataGridProvider>;
```

`reorderRows` and `moveRowsBy` return `true` or `false`.

## Stop a gate that never settles [#gate-timeout]

Set `gateTimeoutMs` to abort an async gate whose promise has not settled in time. The gates are `onBeforeDeleteRows`, `validateRow`, `onEditStart`, `createRow`, `duplicateRow`, `processPaste`, and `import` (the import dialog). Pass one number, or a number per gate name. The default is off. `onGateAborted({ gate, reason })` reports each gate the grid stopped waiting for. The `reason` is `"timeout"`, `"changed"`, `"superseded"`, `"cancelled"`, or `"reset"`.
