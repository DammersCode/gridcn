`updateCells` and `updateRows` check every patch. The verdict tells you what the grid wrote and what it skipped. See [Stream updates](/docs/rows-live-data/stream-updates) for the call.

`updateCells` and `updateRows` return an `UpdateCellsVerdict`:

- `applied` counts the cells the call wrote.
- `skipped` holds one `UpdateCellsSkip` per patch that the grid checked and did not write, with its `patchIndex` and a `reason`. Two patches to one cell in one batch count once, and the last one wins.
- `pending` is `true` while an async schema holds the batch. `settled` resolves with the final verdict. A superseded batch resolves with `applied: 0` and no `skipped` entries.

| Reason | Meaning |
| --- | --- |
| `unknown-row` | The row id is not in `data`. |
| `unknown-column` | The column id is not a known column. |
| `hole` | The id is the placeholder id of an unloaded scroll-mode row. A push by the real id of a row that is not loaded gets `unknown-row`. |
| `readonly` | For a call with a `source` other than `"stream"`: the column is read-only, or the row is read-only through `readOnly(row)`. A `"stream"` call gets this reason for a column with no write path (`accessorFn` without `setValue`). |
| `saving` | A stream call: the row has a save in flight. Push the value again after the save settles. |
| `limit` | A stream call: the call carried more than 100,000 patches, and this patch came after them. |
| `invalid` | The column's `validate` rejected the value. |
| `no-op` | The value equals the current value. |

## Flash changed cells [#flash-cells]

The grid flashes cells on its own only after a fill. A push does not flash. To flash the cells that a push wrote, pass `{ flash: true }` to `updateCells` or `updateRows`. The call flashes the cells it applied at once. A held batch flashes after `settled`. Cells of hidden columns do not flash:

```tsx fragment="inside the feed component"
actions.updateCells(patches, { flash: true });
```

`actions.flashCells(cells, durationMs?)` flashes any cells without a write. Each cell is a `CellRef` with `rowId` and `columnId`. `flashCells` changes no data and adds no history entry. Flashing a cell again resets its timer. `durationMs` sets how long the cell keeps `data-flash`, 1400 by default. `--grid-flash-duration`, `--grid-flash-color`, and `--grid-flash-intensity` style the flash. See [Style contract](/docs/contracts/style-contract).
