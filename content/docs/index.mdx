gridcn is an editable, high-performance data grid for the shadcn/ui ecosystem. It has range selection, copy and paste to and from spreadsheet apps, and a typed column model. It uses real DOM cells, styled with shadcn tokens only. Virtualized row rendering (drawing only the rows in view) keeps it smooth at 100k+ rows. See the [performance benchmarks](/docs/performance/benchmark-results). The
[Terms](/docs/terms-help/terms) page defines the words these docs use for grid concepts.

## Not an npm package

The [shadcn CLI](https://ui.shadcn.com/docs/cli) copies the source files from the hosted
`@gridcn` registry into your project: `npx shadcn add @gridcn/data-grid`. You own the code.
An update re-runs the install.

## Modular by design

The core `data-grid` item is the engine: range selection, keyboard, editing, cell types, and
the spreadsheet clipboard. Every other feature is a separate registry item (see the
navigation), installed with one `npx shadcn add`. Each item is free and
open source under the [Apache License 2.0](/docs/support-upgrades/license-credits). Most add-ons need the core, and some install other gridcn items.

## Project status
