A value that changes on every key fires work on every key. `useDebounce` returns a copy of the value that follows it after the value stays the same for a wait. The hook has no dependency on the grid.

<InstallCommand item="use-debounce" />

The item installs `useDebounce` and [`useDebouncedInput`](/docs/hooks/use-debounced-input) to `components/gridcn/use-debounce.ts`.

## Usage

Pass the value and the wait in milliseconds:

```tsx
const [query, setQuery] = useState("");
const debouncedQuery = useDebounce(query, 300);
```

`debouncedQuery` follows `query` after `query` stays the same for `delayMs`. A new `query` before the wait ends restarts the wait. With `delayMs` of `0`, `debouncedQuery` is `query` itself.

| Argument | Type | Default |
|---|---|---|
| `value` | `T` | none |
| `delayMs` | `number` | `300` |

<Callout type="warn" title="Text typed in an input">
  If the value comes from a text input, use [`useDebouncedInput`](/docs/hooks/use-debounced-input). `useDebounce` does not know about IME composition, so it can pass half-composed text on. It also cannot commit a pending value on blur or unmount.
</Callout>
