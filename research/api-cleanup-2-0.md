# API cleanup for 2.0

One-shot scan of `content/docs` and the public API of `registry/default/blocks/**`. Each item was verified in code and confirmed by a reviewer: a real gain in clarity, cleanliness or prop count, and no lost capability. Skipped by design: `keepCheckedRows`, `keepHiddenCheckedRows`, `checkedRowsLifetime`. Prior decisions (`api-cohesion-2.0.md`, `api-caveat-fixes.md`, `global-shortcut-flags.md`) are not re-opened.

Every item keeps a default, an override, a manual equivalent and a policy hook. Details with file:line, refutation and blast radius per item: shared notes `api-gate-proposals.md`.

| # | Old | New | Why | Migration | Capability check |
|---|---|---|---|---|---|
| 1 | Global shortcut layer fires any binding of a flagged action | Global layer accepts a binding only with Ctrl/Cmd; a bare-key binding warns once in dev and stays in-grid | Removes a destructive trap (Delete on the page body) and a warn callout | None for correct code | Mod-chord remap, in-grid bare keys unchanged; page-wide bare key: own `window` listener calling `api.actions.*` |
| 2 | `importDefaults.autoDetectDelimiter` + `defaultDelimiter` | `defaultDelimiter` only (unset = detect) | Flag is redundant: `false` equals `defaultDelimiter: ","`; dead with a delimiter set | `{ autoDetectDelimiter: false }` becomes `{ defaultDelimiter: "," }` | Detect, fixed delimiter, dialog choice, `parseImportFile(file, { csvDelimiter })` |
| 3 | Label merge lets `undefined` replace a default; grid `labels.pagination` read by nothing; `DataGridViews` ignores grid labels | One chain: default, grid `labels.<set>`, component `labels`; `undefined` never overrides; add `labels.views` | Removes a throw-on-`undefined` trap, a dead key, a warn callout and two "does not reach" rules | Blank a label with `""`; pass grid `labels` once | Per-component override, function labels, bar outside a provider (own `labels`) |
| 4 | `enableRowReorder` plus a reorder `rowMarkers` mode (both needed); `useDataGridRowReorderEnabled` | A reorder marker mode is the switch; hook removed | Prop can leave a grip that does nothing | Delete the prop; lock with `rowMarkers="checkbox"` | Turn off, temporary lock (toggle marker, `readOnly`), `reorderRows` / `moveRowsBy` with their guards |
| 5 | `useDataGridServerPages`, `useDataGridServerScroll` (unreleased aliases) | `useDataGridServerRows({ mode })` only | A second spelling of one hook | `useDataGridServerScroll(o)` becomes `useDataGridServerRows({ ...o, mode: "scroll" })` | Identical behavior; aliases only forwarded |
| 6 | Totals row needs state, callback, memo and a reporter inside the provider; rules on stable arrays, `accessorKey === id`, `refresh()` after saves | `aggregateRow(specs, { cells, scope })`, `serverAggregateRow(opts)` as `PinnedRowSource` entries in `topRows` / `bottomRows` | About 12 wiring lines per demo, 2 rules, 1 warn callout gone; adds 2 helpers | Replace the wiring with `bottomRows: [aggregateRow(...)]` | Reporters stay (outside-provider read); `scope`, reducers, `refreshAfterSave` policy, plain static rows |
| 7 | `DataGridFilterMenu operatorsForColumn` (third precedence layer, menu only) | Column `filterOperators` / cell type `filter.operators` | Menu and header filter could offer different operators | Map the column array once | Per-column, per-type, computed rule; lost: two menus with different sets (contradicts header filter) |
| 8 | `useDataGridFindReplace showScope` | Derived from `totalRowCount` / server mode | The case it was added for is gone; unreleased | Remove; declare `totalRowCount` | Hide via empty `labels.findReplace.scopeLoadedRows` |
| 9 | `storage` and `storageKey` ("ignored when `storage` is set") | `storage: string \| DataGridViewsStorage` | Removes an ignored combination | `storageKey="k"` becomes `storage="k"` | Custom backend, local key, reload on key change, `createLocalStorageViewsStorage` |
| 10 | `locale` repeated on every number/date column and the status bar | Provider `locale` (default `"en-US"`); column `options.locale` and `formatValue` override; status-bar `locale` removed | One concern, one place; net 0 props | Move `locale` to the provider | Per-column override, status-bar `formatValue`, SSR-stable default |
| 11 | `DataGridKeybindingsDialog` + `DataGridKeybindingsShortcut` with consumer `open` state; hard-coded `?` | `useDataGridKeybindings()` returns `{ plugin, open, close }`, `?` bound as keymap action `openKeybindings`; the dialog component stays for custom placement | Same shape as find and replace; no state wiring; `?` remappable; warn callout gone. Risk: `?` is not shifted on every layout, so the matcher must ignore Shift for printable non-letters | Use the hook; button calls `open()` | Controlled dialog, own trigger, remap/unbind via keymap |
| 12 | `DataGridSearch captureFindShortcut` (hard-coded Mod+F, default `true`) | Core keymap action `focusSearch`, default `mod+f` | One owner per chord, remappable, listed in the dialog; prop gone. Ship only together with 11 | `captureFindShortcut={false}` becomes `keymap={{ focusSearch: [] }}` | Unbind, rebind, find-replace precedence, per-grid scoping |

Order of work (benefit/cost): 1, 2, 3, 4, 5, 7, 8, 9, 6, 10, 11 + 12.
Judgment calls for the owner: 6 adds two exports, 10 adds one core prop; both are defended by removed repetition, not by prop count.
