# API gate docs delta

Docs pages that the API-gate branch changes make stale. The docs session owns `content/docs`; this list is the work order after the docs head merges. Page lists come from grep at the branch head and may miss pages that use the old shape in prose only. After the edits run `pnpm docs:generate` for generated pages (`messages.mdx`, `actions-z.mdx`, `props-z.mdx`, `options-z.mdx`), `node scripts/verify-parity.mjs --write`, and add the removed names to `REMOVED_NAMES` in `scripts/verify-skills.mjs`.

Every Breaking row below also needs a row in `(evaluate)/support-upgrades/migrate-2-0.mdx`; the CHANGELOG `**Breaking:**` entries hold the migration text.
